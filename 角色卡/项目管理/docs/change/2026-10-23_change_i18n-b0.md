## 二、公共 API 与语义（冻结）

`index.ts` 导出：

- `Locale = "zh-CN" | "en-US"`；`SUPPORTED_LOCALES` 只读数组（运行时冻结）；`DEFAULT_LOCALE = "zh-CN"`；`isLocale(value)`；`resolveLocale(value: unknown): Locale`（白名单精确匹配；`en`/`zh`/大小写变体/空白/非字符串回退默认；`preferences.locale.invalid` 由调用方记录）。
- `MessageKey`（13 个 B0 key）、`MessageParams = Record<string, string | number>`、`MessageTemplate = string | Partial<Record<Intl.LDMLPluralRule, string>>`、`Catalog`、`PluralCategory`、`CatalogOverrides`。
- `translate(locale, key, params?, options?): string`；`createTranslator(locale, options?): (key, params?) => string`。
- `TranslateOptions.onDiagnostic?: (d: TranslateDiagnostic) => void`；`TranslateOptions.catalogs?`（仅测试/嵌入，生产不传）。
- `TranslateDiagnostic = { code: "i18n.missing-key" | "i18n.missing-param"; locale; key; param?; severity: "warning" | "error" }`。
- `formatNumber`、`formatDateTime`、`selectPluralCategory`；`zhCN`、`enUS`。

回退/插值/复数/诊断语义与验收 P4 一致：当前 locale → zh-CN → key；en 缺 → zh + warning；两目录缺 → key + error；缺参数保留 `{param}` + warning；复数用 `Intl.PluralRules`，缺所选变体回退 `other`，缺 `other` → key + error，缺/非数字 `count` → `other` + warning。诊断回调抛错被吞掉（不中断翻译）。不做 HTML 转义；不修改入参；返回新字符串。

**B0 初始 key（准确名称，供桌面UI/桌面窗口消费）**：

`ui.settings.language.title`、`ui.settings.language.description`、`ui.settings.language.zhCN`、`ui.settings.language.enUS`、`ui.settings.language.saveFailed`、`main.window.title`、`main.dialog.importProject.title`、`main.dialog.pickImage.title`、`main.error.startup.title`、`main.error.startup.detail`、`preferences.error.invalidLocale`、`preferences.error.saveFailed`、`preferences.error.readInvalid`。
