## 二、行为契约（实现值）

### 2.1 偏好文件

- 路径：`<userData>/ans/preferences.json`（`preferencesFilePath(app.getPath("userData"))`；与 `runtime-selection.json` 同目录）。
- 形状：`{"version":1,"locale":"zh-CN"|"en-US"}` + 换行；写入用共享 `src/common/shared/atomic-write.ts::atomicWrite`。
- 首次启动无文件：**不写**（`readPreferences` 返回 `state:"missing"`，不创建文件/目录）。
- 用户切换：写文件成功后才更新内存与 translator。
- 降级（不阻塞启动）：损坏 JSON → `preferences.read.invalid`（`corrupt-json`）；非法 locale → `preferences.locale.invalid`（`invalid-locale`）；未知 version → `preferences.read.invalid`（`unsupported-version`）；不可读 → `preferences.read.invalid`（`unreadable` + `errorCode`）；写失败 → `preferences.write.failed`（`write-failed`/`persistence-unavailable` + `errorCode`）。诊断码/reasonCode 是机器标识，**不翻译**。
- 不写项目 `.ans`、`.env`、治理账本；不读真实凭据。

### 2.2 IPC / preload

| preload 方法 | IPC / 参数 | 返回 |
| --- | --- | --- |
| `getPreferences()` | `preferences:get`（无参） | `{version:1, locale, supported:string[]}` |
| `setLocale(locale)` | `preferences:set-locale` `{locale:string}` | `{ok:true, locale}` \| `{ok:false, locale:当前, error}` |
| `onLocaleChanged(cb)` | 订阅 `preferences:locale-changed`（主→渲） | `{locale}`；返回取消订阅函数 |

- 推送只在**写成功**后发生；非法/写失败不广播、不改内存/文件。
- 既有 IPC 载荷/业务通道未改。

### 2.3 偏好服务 API（可测试）

```ts
readPreferences(filePath): Promise<{state:"missing"|"valid"|"invalid"; locale:Locale; diagnostics:PreferencesDiagnostic[]}>
writePreferences(filePath, locale): Promise<void>            // isLocale 白名单；atomicWrite
createPreferencesService({filePath?, initialLocale?, onDiagnostic?}): {
  getLocale(); getView();                                    // {version:1, locale, supported}
  setLocale(value: unknown): Promise<{ok:true,locale}|{ok:false,locale,error:"invalid-locale"|"persistence-unavailable"|"write-failed"}>
}                                                            // error 为稳定码；IPC 层映射为 preferences.error.* 文案
```
