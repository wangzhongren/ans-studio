# 产品 功能导航

## 说明

- 功能点 = 用户或外部系统能触发并得到结果的行为；本角色不自编业务功能，上表登记的是本角色的产出物类型。
- 提案文档按 `docs/design/` 规范：每条含问题/现状、依据、交互、验收、优先级；本轮最高建议仅三项P1，没有当前证据支持新增P0。源码推断不当作真机观察，已修旧问题不重新开单。
