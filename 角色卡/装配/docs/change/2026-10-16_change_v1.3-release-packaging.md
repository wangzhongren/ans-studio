## 发布说明素材要点（本版功能面一句话清单，供 notes 起草）

- **G-3 三平台联网搜索（默认关）**：Pi/Claude/Codex 三适配器接入服务端联网搜索工具；平台各自开关、默认关闭；查询串不进诊断落盘；失败如实报告、不毁轮次（自动剥离重试后置）。
- **工具行按轮折叠**：同一轮工具调用在轮结束后折叠为一行（「本轮 N 个调用：…」），运行中实时可见；展开逐条零丢失；折叠态标出未放行/失败调用。
- **G-4 角色能力安装**：su 可把**技能**（V1）与**外来 MCP 服务器**（V2）装进项目角色——stdio 限定、名称受限；Claude/Codex/Pi 三平台装配（Claude 收窄 env 启动器 / Codex 白名单化 / Pi 自持 transport）；`docs/skills`、`docs/mcp` 预授权树内免确认直写；卸载＝下次会话摘除、已发生副作用不可撤；能力级授予（非逐调用受审）。
- **G-5 推理强度**：新会话可选推理档位（关/低/中/高/极高；未设＝逐字现状）；Pi/Claude/Codex 三平台各一字段；推理内容以「已思考 N 秒 ▸」折叠行呈现；网关拒绝时恰一次去参数重发降级并如实标注；思考计入输出 tokens。
- **修复**：Codex 行确认 URL 贪婪收窄（`cleanPatterns`，含 Codex 诊断同批）。
