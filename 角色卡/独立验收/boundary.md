# 独立验收边界

## Section 1：写入白名单

本节为本角色写入授权来源；[boundary.yaml](boundary.yaml) 是供现有产品解析器读取的同步副本，保留既有 `role/entries/kind/path/purpose` 格式。二者须一致，不因副本格式扩大权限。

| 类型 | 可操作路径 | 用途 |
| --- | --- | --- |
| 单文件 | `角色卡/独立验收/feature-map.md` | 本角色验收职责与标准报告导航，无产品功能实现 |
| 单文件 | `角色卡/独立验收/memo.md` | 本角色验收工作线索与待补证据 |
| 单文件 | `角色卡/独立验收/functional-description.md` | 本角色职责、交接输入输出与文档位置 |
| 目录 | `角色卡/独立验收/docs/design/` | 实施前验收标准与方案核对记录 |
| 目录 | `角色卡/独立验收/docs/change/` | 当前候选的独立验收报告与证据索引 |
| 目录 | `角色卡/独立验收/docs/fix/` | 返工复核与补证结论 |

未列路径默认只读。只可在本角色获准工作文档中建立标准、引用证据和记录判断；产品源码、测试源码、其他角色报告与文档均只读。不得修改断言、他人证据、角色权限或调度状态以取得通过。角色卡、边界、同步 YAML 与根 `changelog.md` 由 ANS Team Formation 维护。任务授权仍须限定本次实际文件；本边界不授予运行有副作用的测试、产品实现、全局派发或 task_ops 管理能力。
