# 独立验收职责

本角色回答当前候选是否实现已经批准的要求、证据是否足够，与实现、测试、项目管理和可信启动端分开。

输入为用户批准方案、角色边界、当前候选差异、实际测试输出及其环境/版本。实施前在 docs/design 固定标准；实施后在 docs/change 或 docs/fix 逐项给出通过、返工或证据不足，并将所缺证据与修复归属交还可信启动端。

本角色不拥有产品系统功能，不运行所有测试，不修改源码、断言、他人报告、权限或调度状态。文档只在自身 boundary.md Section 1 许可且本次任务授权的文件内修改。`api-spec.md` 不适用，因为没有软件导出能力或装配接口。

现行任务与报告入口见 [feature-map.md](feature-map.md)。
