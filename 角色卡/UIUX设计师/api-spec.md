# UI/UX 设计师交付约定

本角色没有程序导出或业务 API。本文件说明设计产物如何交给产品、项目管理与实现角色，具体方案产生后补充实际设计版本和检查证据。

| 项目 | 约定 |
| --- | --- |
| 输入 | 产品目标、当前真实界面与任务状态、产品评审意见、客户约束及任务议程 |
| 布局与交互说明 | 说明用户任务、适用窗口、信息层次、关键操作和成功/失败/空态；区分观察、推断和建议 |
| HTML 原型 | 落本角色 `docs/design/`；说明打开入口、演示数据、可检查交互、模拟能力与未接入部分，素材在同目录范围内 |
| 设计规范 | 交付任务所需的尺寸、间距、颜色、组件状态、文案与焦点/键盘行为及验收口径 |
| 联合评审 | 在独立固定角色上下文贡献设计意见，由项目管理记录纪要与客户实际决定 |
| 实现交接 | 引用具体方案版本、检查证据、尚待验证状态与属主；由项目管理审核后交客户确认实施范围 |
| 权限变化 | 返回项目管理并由 Governance 处理，不由设计师自行扩大范围 |
