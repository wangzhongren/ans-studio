## 五、I9 P6：200% 设置保存条可达（布局收口）

**发现（I9，`角色卡/测试/docs/change/2026-10-23_change_i18n-integration.md` §6.3）**：960×620 物理窗口 @200% = CSS 480×310 时，设置面板可用高度仅 210px；语言区（zh 86 / en 103）+ 引擎 tabs 34 + 保存条 64 超过面板高度，原 flex 布局把保存/状态条推到视口下方（I9 记录 y≈332–361，候选复现 y≈299–327），`#pi-save` 中心在视口外、`elementFromPoint` 命中失败 → P6 fail。

**修法（仅渲染层 CSS，不改固定高度/最小窗口/设计基线，无需 UIUX 新规格）**：`phase4a.css` 新增短视口媒体查询 `@media (max-height: 480px)`：

- `#pi-panel.pi-panel`：`display:block; overflow-y:auto; overscroll-behavior:contain; scroll-padding-bottom:64px`（面板整体可滚；键盘聚焦时避开底部保存条）；
- `#pi-panel .pi-tabpanel`：`display:block; min-height:0`（解除 flex 高度约束）；
- `#pi-panel .pi-scroll`：`overflow:visible`（内容随面板滚动，不再嵌套内层滚动）；
- `#pi-panel .pi-save-bar`：`position:sticky; bottom:0; z-index:1`（保存条始终贴视口底）。

960×620（CSS 高 620）不命中该媒体查询，原 flex 布局与保存条 `static` 位置保持不变。

**真实 Electron 复验**（真实 Electron 渲染层构建产物 + 真实 `app/preload.cjs` + IPC 替身；临时 userData；无模型/网络；`layout-200pct-electron-smoke.mjs`；zh/en 各自独立启动）：

| 场景 | 结果 |
| --- | --- |
| 960×620 zh-CN | 保存按钮中心命中 `true`；面板 `flex/overflow visible`、保存条 `static`（原布局不变）；侧栏 208；`doc.sw=960=cw` |
| 960×620 en-US | 同上；保存按钮命中 `true` |
| 480×310（200%）zh-CN | 面板 `block/overflow-y:auto`，`scrollHeight 763 > clientHeight 210`；保存条 `sticky` y=246–310（在视口内）；`#pi-save` y=264.5–292.5、中心命中 `true`；滚到底后仍命中 |
| 480×310（200%）en-US | 面板 `scrollHeight 846 > clientHeight 210`；保存条 `sticky` y=246–310；`#pi-save` 中心命中 `true`；滚到底后仍命中 |

- 截图：`layout-200pct/zh/settings-960-zh.png`、`settings-200-zh.png`、`settings-200-zh-bottom.png`；`layout-200pct/en/settings-960-en.png`、`settings-200-en.png`、`settings-200-en-bottom.png`。
