## 二、用户可见入口与行为

**入口**：设置抽屉（右抽屉 “Pi/Codex/Claude” 设置面板）顶部新增“语言”区：
`#pi-language-section` → `#pi-language-title`、`select#pi-language-select`（`zh-CN` 显示 `简体中文`、`en-US` 显示 `English`）、`#pi-language-description`、失败错误 `role="alert"`。语言区位于 `.pi-engine-tabs` 之前；引擎设置与保存条布局未变。

**行为**（B0 骨架）：

1. 默认 `zh-CN`，不跟随 OS 语言。
2. 首屏：store 创建时同步读 `localStorage["ans.locale"]`（合法值才用）；`init()` 更新 `document.documentElement.lang`，再调用 `getPreferences()` 以偏好文件为准校正并回写镜像；订阅 `onLocaleChanged` 广播（重复/并发 init 不重复订阅）。
3. 切换：乐观更新 store / `lang` / 镜像 → `window.desktop.setLocale`；`ok:true` 保留；`ok:false`/异常回滚三者并显示本地化错误（按回滚后的语言渲染 `ui.settings.language.saveFailed`）；非法值拒绝；IPC 不可用（旧 preload/测试替身）时只保留本地镜像，不崩溃。
4. 启动期间用户已切换或已收到广播时，晚到的偏好文件快照不覆盖（方案 §4.6 优先级：本次运行用户切换 > 文件）。
5. `t(key, params?)` 调用 shared `translate`；`useT()` 随 locale 返回新的 translator。facade/store 无第二份目录、插值、复数或回退实现。

**验证的代码位置**：

- facade：`app/renderer/src/i18n/index.ts`（shared 相对导入 `../../../../src/common/shared/i18n/index.ts`）
- store：`app/renderer/src/i18n/locale-store.ts`（`createLocaleStore`、`init`、`setLocale`、`t`、`productionDeps`）
- 桥声明：`app/renderer/src/lib/platform.ts`（`getPreferences`/`setLocale`/`onLocaleChanged` 可选方法；渲染层只经 `getDesktopBridge()` 访问）
- 启动：`app/renderer/src/App.tsx` 启动 effect
- 语言区：`app/renderer/src/shell/SettingsPanel.tsx` `LanguageSection`（标记 `// ---- 语言区（B0）开始/结束 ----`）
- 守卫：`test/桌面UI/source-guard.test.ts` localStorage 白名单

## 三、locale store API / 状态语义

`LocaleStoreState`：`locale: Locale`（默认 `zh-CN`）、`error: string | null`、`initialized: boolean`；动作 `init(): Promise<void>`、`setLocale(next: string): Promise<boolean>`、`t(key, params?)`。

- 工厂 `createLocaleStore(deps)`：`readStoredLocale`/`writeStoredLocale`/`applyDocumentLang`/`getBridge`/`onDiagnostic` 全部注入；测试不触碰真实 `window`/`localStorage`/`document`。
- 诊断码（机器标识，不翻译）：`locale.mirror.invalid`、`locale.preferences.readFailed`、`locale.preferences.saveFailed`、`locale.subscribe.failed`。
- 存储键常量 `LOCALE_STORAGE_KEY = "ans.locale"`（镜像只放语言；治理/报告事实不写 localStorage）。
- 生产单例 `useLocaleStore` 是 zustand vanilla `StoreApi`（`getState()/subscribe()`）；组件用 facade 的 `useLocaleState(selector)`，翻译用 `useT()`。
