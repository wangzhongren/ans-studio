冻结对象与形状
-------------
Pipeline 公共句柄（src/pipeline/orchestration/customer-directive.ts）：
  createCustomerDirectiveRuntime(opts: { projectRoot; sessionId; present: DirectivePresenter; now?; store? })
    → CustomerDirectiveRuntime
  CustomerDirectiveRuntime:
    submitFromInput(input: SubmitFromInput) → Promise<SubmitResult>
    approvalFacts() → ApprovalDirectiveSnapshot（只含 approval；ledgerErrors>0 ⇒ active=[]）
    decisionFacts() → DecisionDirectiveSnapshot（只含 decision；同上）
    takeDirective(req: ShellReviewRequest, intent?: "allow"|"deny") → Promise<ApprovalDirectiveDecision | undefined>
    applyDecisionDirective(card: DecisionCardFacts, hooks?: DecisionHooks) → Promise<DecisionApplyResult | undefined>
    revoke(id, target) → Promise<RevokeResult>
    list() → Promise<DirectiveListResult>
  SubmitFromInput.decisionGroupEnabled: boolean（必填、无默认）
  DecisionHooks.emitResult 为唯一可见行钩子（无 deliver 别名）；抛错/拒绝/无钩子 ⇒ 不消费、不应用、返回 undefined。
  DecisionApplyResult = selected | rejected | conflict | no-match（conflict/no-match 不消费任何指令）。
  DirectiveErrorCode = cancelled | presenter-unavailable | invalid-input | high-risk-unacknowledged |
    ledger-write-failed | ledger-unavailable | not-found | target-mismatch | already-consumed |
    already-revoked | expired。
  DirectiveStore.append(line): Promise<void>（durable 后 resolve；失败 reject；relPath 必须 === CUSTOMER_DIRECTIVES_REL）。

takeDirective 语义（冻结）
-------------------------
  · 只读 approval target；精确匹配 normalizeCommandText(req.command) 与 resource.cwd（同目录比较）。
  · 未匹配/ledgerErrors>0/消费失败 ⇒ undefined（回落既有路径），绝不重复使用 once。
  · once 在返回前 durable consume；session/forever 只返回、不写非状态事件。
  · 公共一参调用：先 deny 后 allow。可选 intent 仅为 B1 shell gate 内部消费阶段提示
    （"deny" 预检 / "allow" 应用），不改变 C1 可见的一参调用语义。

shell 闸（src/common/编排/shell-gate.ts）
----------------------------------------
  · CreateShellGateOptions.takeDirective?: TakeDirectiveFn；readonlyOnly === true 时构造期抛错。
  · 顺序：preblock → write-guard → classify → 指令 deny → c=deny → c=allow → script →
    既有 takeGrant → 指令 allow → 既有 advisory/operatorOnly/三层链。
  · 审计 ShellAuditRecord.directive?: { id, scope }；by = "directive:<id>"；
    ShellReviewResult.directive?: { id, scope }；ShellGateReviewedOutcome.directive?: { id, scope }。
  · 与 judge/customerGrant 互斥；directive 分支不写 judge/customerGrant。
  · 分支常量：BRANCH_DIRECTIVE_ALLOW="directive:allow" / BRANCH_DIRECTIVE_DENY="directive:deny"。
