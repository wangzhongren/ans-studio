# 产品意图：贪吃蛇游戏（v1）

## 目标用户与场景
- 目标用户：想要在桌面环境下快速上手玩一局贪吃蛇的普通玩家；无需账号、无需联网。
- 使用场景：用户打开游戏即可用键盘方向键操作蛇移动、吃食物得分；一局结束后可一键重开再来一局；撞到场地边界即本局结束。

## 要解决的问题
客户希望获得一个从零交付的、可玩的贪吃蛇游戏，核心体验是「键盘控制 + 计分 + 重开 + 边界碰撞」四项能力齐备，能够完整玩完一局并重新开始。

## 范围与非目标
- 范围内（客户明确要求，不可裁剪）：
  1. 键盘方向控制（上/下/左/右）；
  2. 计分（吃食物加分并显示分数）；
  3. 重开（重置本局重新开始）；
  4. 边界碰撞（蛇头撞边界即结束本局，不可穿墙）。
- 非目标（客户未提出，明确排除）：联网/在线排行、音效、移动端触控、关卡、皮肤/主题、账号、多人模式。
- 不附加任何客户未提出的功能要求。

## 成功/验收标准
1. 键盘方向键可控制蛇移动，方向输入被游戏正确响应。
2. 吃到食物后分数正确累加，并在界面上实时可见。
3. 提供明确的重开入口，重开后蛇、分数、场地状态归零重置。
4. 蛇头触碰场地边界即判定碰撞并结束本局，不存在穿墙。
5. 四项能力在同一局游戏内同时成立，形成完整可玩闭环。

## 客户原话与约束
- 客户原话：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）」。
- 约束：四项必须能力为硬性范围，不得裁剪，也不得附加客户未提出的功能；项目从空项目起步（当前非 Git 仓库、无 run）。

## 质量档位
- 档位：可玩演示级（Playable Demo）——以四项能力正确可用、单局流程完整闭环为准；不追求美术精细度、性能调优或扩展玩法。
