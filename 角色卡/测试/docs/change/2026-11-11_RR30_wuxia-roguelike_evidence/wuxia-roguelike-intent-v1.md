# 产品意图：wuxia-roguelike（武侠肉鸽生存 2D 小游戏）

## 1. 目标用户与场景

- 目标用户：偏好武侠题材、喜欢短局肉鸽与“越打越强”成长体验的玩家。
- 使用场景：单人、碎片时间游玩（建议单局 3-5 分钟）；浏览器直接打开静态页面即可开始，无需安装客户端、注册账号或联网。
- 操作预期：MVP 以键盘移动（WASD/方向键）为主，自动攻击降低瞄准负担，玩家专注走位、拾取与构筑选择。

## 2. 要解决的问题与产品价值

- 降低上手门槛：自动攻击四周敌人，玩家不需要手动瞄准即可持续输出。
- 短局成长爽感：一波波敌人带来压力，击杀与拾取经验推动升级，三选一强化与武器/道具收集形成单局构筑。
- 可重复游玩：失败可快速重开，胜利有明确结算，单局闭环完整。
- 交付友好：纯前端静态页、无后端依赖，便于直接打开、分发与验收。

## 3. 客户原话与关键需求要素

> 使用 ans-studio 开发一个 2D 小游戏：类似《土豆兄弟》(Brotato) 的肉鸽生存游戏，武侠风格。玩家在武侠场景中自动攻击四周敌人，撑过一波波敌人、拾取经验升级并从强化选项中选择、收集武器与道具；纯前端静态页面（HTML/CSS/JS），可玩即可。

关键需求要素：

1. 类型与题材：2D 肉鸽生存，类似《土豆兄弟》，武侠风格。
2. 战斗：玩家自动攻击四周敌人。
3. 进程：一波波敌人，撑过波次/达成生存目标。
4. 成长：击杀与拾取经验，升级后从强化选项中选择。
5. 收集：武器与道具的获取与使用。
6. 技术形态：纯前端静态页 HTML/CSS/JS。
7. 质量目标：可玩即可。

## 4. 范围

本版（v1）范围以“可玩闭环”为边界，包含：

- 单局核心循环：开始 → 自动攻击清怪 → 波次推进/计时 → 胜负结算 → 重开。
- 玩家角色：移动、生命、受伤与无敌帧、死亡判定。
- 自动攻击：自动索敌，按范围/冷却对敌人造成伤害，无需手动瞄准。
- 敌人与波次：至少 2-3 种敌人，按波次或时间刷新，强度逐波递增；精英或首领可作为可选内容。
- 经验与升级：击杀敌人掉落经验，玩家拾取；经验达到阈值触发升级，提供至少 2-3 个强化选项供选择，选择后效果可感知。
- 武器与道具：至少 1 种武器或道具可通过实际玩法获取并使用/生效，体现“收集与成长”。
- 界面与反馈：开始界面、HUD（生命、等级/经验、波次/计时）、强化选择面板、胜负结算与重开。
- 武侠主题呈现：通过命名、配色、字体、技能名等最低限度体现武侠风格。
- 技术形态：纯前端 HTML/CSS/JS 静态页，无构建链亦可直接打开运行，无后端。

## 5. 非目标

- 无后端服务、数据库、账号/登录。
- 无联网对战、联网排行榜、云存档。
- 无付费/内购。
- 不做复杂剧情、关卡编辑器、资产管线。
- 不做高精度美术、动画、配音。
- 不做移动端触屏适配、音效、多语言。
- 不做复杂元进度、长期养成、成就系统。

## 6. 成功/验收标准

- AC-1 可直接打开入口页面进入游戏，无需安装依赖、构建或启动服务器，页面无阻断性报错。
- AC-2 玩家可移动、受伤、死亡；敌人会持续出现并构成威胁。
- AC-3 自动攻击生效：无需手动瞄准即可对范围内或最近敌人造成伤害。
- AC-4 波次可推进并产生明确胜负结算，结算后可重开并再次完整游玩。
- AC-5 击杀敌人可获取经验，经验达到阈值触发升级，升级出现至少 2-3 个强化选项且选择后效果可感知。
- AC-6 至少 1 种武器或道具可通过实际玩法获取并使用或生效。
- AC-7 HUD 可读：生命、等级/经验、波次/计时等关键信息可见。
- AC-8 单局 3-5 分钟内可完成“移动—自动攻击—清怪—拾取—升级—强化—再战”闭环，离线可玩。

## 7. 质量档位

可玩原型级（prototype-playable）：

- 功能闭环完整，关键路径无阻断性错误；
- 离线、直接打开即可游玩；
- 美术、音效、性能与兼容性达到“基本可用”即可，不追求商业级打磨与内容量。

## 8. 约束与假设

- 交付形态为静态文件，建议提供可直接打开的入口页面（如 index.html）；资源随包提供，不依赖外部 CDN 或版权素材。
- MVP 输入以键盘为主，鼠标可选；触屏/移动端适配不在本版范围。
- 数值与平衡只要求“能玩通/能失败”，深度平衡不作为硬验收。
- 本文件只描述产品意图与验收口径，不写实现方案；实现路线由后续提案阶段决定。
- 意图确认由客户本人决定，本文件不替代客户确认。

## 9. 待客户确认项（供意图确认参考，不代客户决定）

- 移动端触屏适配是否必须纳入 MVP；
- 是否要求音效；
- 单局目标时长是否采用建议的 3-5 分钟；
- 是否需要本地最高分记录；
- 入口页面命名与打开方式是否有偏好。
