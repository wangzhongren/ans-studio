---
intentId: snake-2d-game
flowId: snake-game
version: 1
goal: 交付一个纯前端、无第三方依赖、浏览器直接打开即可玩的 2D 贪吃蛇单页小游戏，具备计分、最高分持久化与重新开始能力。
scope: 纯前端 HTML5 Canvas 单页游戏（index.html 及若干 js/css 文件）；方向键与 WASD 控制；吃食物加分并变长；撞墙或撞自身判定游戏结束；当前分数与最高分（localStorage）显示；结束后按 R 或点击按钮重开；深色背景 + 网格棋盘的简洁界面。
acceptance: 见正文「验收标准」AC-1 至 AC-10，全部为可人工执行、可观察判定的检查项；核心必测项为 AC-1、AC-2、AC-6、AC-7、AC-8。
nonGoals: 不做后端服务、账号/登录、在线排行榜或任何联网功能；不做移动端触屏操作与响应式适配要求；不做音效、皮肤系统、多关卡/障碍物/道具；不做多人对战；不引入第三方库、构建工具或包管理器；不覆盖与游戏玩法无关的营销页、埋点与运营功能。
constraints: 纯前端、零第三方依赖；产物为静态文件，无需构建、无需本地服务器即可用浏览器直接打开运行；最高分仅存于本地浏览器 localStorage；界面深色背景 + 网格棋盘、风格简洁；关键节点（意图、提案、角色与团队、验收等）均需出卡由客户确认，实现与测试完成后须向客户说明产物路径与运行方式。
