# snake-game 产品意图 v1

> 本文件为产品意图（A2 交付物），用于 A3 意图确认。只描述目标、范围、验收与约束，不含实现方案、技术选型与代码。意图入口 `docs/intents/<intentId>.md` 由幕僚在 A3 前落盘。

## 1. 目标用户与场景

- 用户：单人本地玩家，希望打开即玩、无需注册与联网。
- 场景：一局数分钟；用键盘操控蛇在网格中移动、吃食物得分、撞墙后结束，并立刻再来一局。
- 使用门槛：无需教学，界面自解释；失败不惩罚，可无限次重开。

## 2. 要解决的问题

让玩家以最低门槛获得一局完整、可反复的经典贪吃蛇体验：输入可感知（键盘控制）、反馈即时（计分）、失败可达（撞墙即结束）、失败可再来（重开）。四项要求分别对应可操作性、反馈、失败判定与可重复游玩，缺任一项闭环即不完整。

## 3. 范围

### 3.1 纳入范围（验收对象）

1. 单人贪吃蛇核心玩法（移动、吃食物、成长）。
2. 键盘方向控制：方向键与 WASD 均可控制；禁止 180° 反向移动。
3. 实时计分：每吃一个食物分数即时 +1，并在界面显著位置显示。
4. 撞墙（边界）判定结束：蛇头触及或越过边界即本局结束，结束后不再响应移动输入。
5. 结束提示与重开：结束画面显示「游戏结束」与最终分数，提供按键或按钮立即重开；重开后分数清零、蛇身与食物重置。

## 5. 非目标

联网、多人对战、账号登录、排行榜、移动端触控、音效与美术资源、存档、暂停、难度/加速、特殊食物、最高分记录、商业化功能——均不纳入 v1，不作为验收内容。

## 6. 客户原话与约束

- 原话要点：「做一个贪吃蛇游戏」，要求键盘方向控制、实时计分、游戏结束后可重开、撞墙（边界）判定结束（转引自 A1 受理记录，未增删语义）。
- 客户仅给出上述四项，其余细节由本意图在范围内做产品层取舍，技术层取舍交方案阶段确认；不得替客户默认纳入或排除客户明确提出的要求。

## 7. 质量档位

- 定位「最小可玩闭环优先」：四项要求必须真实可用、行为可复现、可连续多轮游玩，不接受概念演示或半成品。
- 可玩性底线：操作响应足以判断方向、计分不跳变、结束与重开状态干净无残留、无崩溃卡死。
- 非承诺项：视觉精致度、美术资源、音效表现、跨平台一致性——除非客户后续明确要求。
