---
intentId: snake-game-mvp
flowId: snake-game
goal: 从零交付一个本地浏览器打开即玩的最小可玩贪吃蛇游戏，覆盖键盘控制、计分、重开与边界碰撞四项需求（零安装、零联网）。
scope: v1 交付范围：方向键与 WASD 均可转向且禁止 180° 反向、仅四方向移动；分数初始 0 且每个食物 +1 并实时可见；本局结束后按 R 或空格重开且分数归 0、蛇与食物重置；蛇头碰任一区域边界立即结束并显示游戏结束与本局最终分数；单区域网格呈现、固定节拍移动、食物随机生成于空格；本地双击网页即可运行、无第三方在线依赖。
acceptance: |-
  AC1 键盘控制：方向键或 WASD 均能改变移动方向；反向键输入被忽略、蛇不反向；蛇始终沿四方向之一移动，无斜向。
  AC2 计分：开场 0 分；每吃到一个食物 +1；分数实时可见；结束后保持显示直至重开。
  AC3 重开：撞墙结束并显示结束信息与最终分数后，按 R 或空格开新局；分数归 0、蛇回到初始长度与位置、食物重新生成，可正常继续。
  AC4 边界碰撞：蛇头接触任一边界时本局立即结束，蛇停止移动与计分，界面明确显示结束状态与本局最终分数。
  AC5 可玩闭环：在无安装、无联网的本地浏览器环境中完成「开始→移动→吃到食物→撞墙→重开」全流程且无崩溃。
nonGoals: 联网/多人对战/在线排行榜；账号与云端存档；美术素材、音效、动画特效；移动端触控与响应式适配；穿越边界（wrap）、暂停、加速等级、障碍物、关卡系统；最高分持久化与历史记录；交付级打磨（高 DPI、可访问性等）。
constraints: 质量档位为可玩原型/内部演示（逻辑正确、操作可感知、无崩溃、界面可读）；交付形态为本地可直接打开的网页单页，不引入联网服务与第三方在线依赖；待澄清项（界面形态、计分权重、最高分持久化、蛇自撞、移动速度）不阻塞 v1，需调整时另出新版本意图。
