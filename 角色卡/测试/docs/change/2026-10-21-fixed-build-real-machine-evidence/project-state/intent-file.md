# 意图记录：最简待办清单网页应用

## 客户原话
> 我想做一个最简单的待办清单网页应用，请先确认需求。

## 目标
交付一个可直接在浏览器打开使用的单页待办清单应用，最小可用功能集：新增、完成/取消完成、删除、列表与空态，数据在刷新后保留。

## 范围
- 包含：单页前端、单用户、本机使用；新增（非空 + 长度上限）、完成/取消完成、删除、列表展示、空态提示、本地存储持久化、加载/空/错误态、基本可访问性、README（启动/架构/schema/限制与权衡）。
- 不包含：账号与多用户、后端与数据库、云同步、协作、提醒、标签/优先级/搜索/排序拖拽、国际化、主题定制、原生 App。

## 待客户确认的关键假设
1. **质量档位**：客户未指定档位，按默认**生产档**执行（不因“最简单”自行降档为原型）；若客户只想快速原型，请在确认卡选 `revise` 并说明。
2. **单用户、无登录**，数据只存本机浏览器，不做云端同步。
3. **零后端**：纯静态前端，可直接用本地静态服务器启动；技术选型与模块划分属提案权，由提案角色决定，不在本意图中指定。

## 验收标准
见 frontmatter `acceptance`（12 条，逐项可核对，含质量档位、工程质量基线与“验收前真实启动并演示”要求）。
