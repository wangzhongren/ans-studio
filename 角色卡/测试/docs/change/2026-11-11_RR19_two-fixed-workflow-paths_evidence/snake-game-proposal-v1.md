# 贪吃蛇游戏 · 策划方案（snake-game v1）

依据意图：`docs/product/snake-game-intent-v1.md`（产品意图 v1，intentId `snake-game-core`；客户于 A3 确认，decisionId `decision-req-b0d663d1200a8ca3`）。本方案的范围、非目标与验收口径均绑定该意图，不扩大授权。

## 一、交付目标

交付一份**单文件 `index.html`** 的贪吃蛇游戏：HTML/CSS/JavaScript 全部内嵌，双击或用现代桌面浏览器直接打开即可运行；无构建步骤、无包管理、无外部依赖、无网络请求。玩家用键盘方向键控制蛇移动，吃食物加分，撞墙结束，结束后可重开且分数归零。

## 二、范围

1. 运行形态：单文件 `index.html`，浏览器直接打开即可开始游戏。
2. 键盘控制：方向键（上/下/左/右）改变蛇的移动方向；可选支持 WASD，但方向键为验收必测项。
3. 禁止 180° 反向：输入方向与当前前进方向相反时忽略该输入；同方向或垂直方向输入正常生效。
4. 食物与计分：蛇头进入食物所在格，分数 +10，蛇身增长一格，食物在未被蛇占据的格子重新生成。
5. 撞墙即结束：蛇头越出游戏区域边界时立即结束，停止移动与计分，显示结束状态与最终分数。
6. 重开：结束状态下通过「重开」按钮或 R 键开始新一局；分数归零，蛇回到初始位置与初始方向，食物重新生成。
7. 基础画面：游戏区域、蛇、食物、当前分数、结束提示与重开入口。

## 三、非目标（本版不实现）

- 不做网络多人对战、联机或观战。
- 不做持久化排行榜、账号体系或历史成绩存档。
- 不做移动端触控、虚拟摇杆或手柄支持。
- 不做音效、复杂动画与美术资源。
- 不做后端服务、数据库与用户数据采集。
- 不做暂停、加速等级、穿墙模式、障碍物等扩展玩法。
- 「蛇头撞自身」不纳入本版判定与验收。

## 四、结构与关键实现取舍

- **单文件内聚**：页面骨架、样式、游戏脚本全部写在 `index.html` 内（`<style>` + `<script>`），不拆外部文件、不引入第三方库，确保「即开即玩」与可完整审阅。
- **逻辑分层（文件内）**：配置与常量（网格尺寸、节拍、分值）→ 游戏状态（蛇身、方向、食物、分数、阶段）→ 输入处理 → 游戏循环（tick）→ 规则判定（进食/撞墙）→ 渲染 → 结束/重开。逻辑分层只在单文件内组织，不产生额外模块路径。
- **渲染取舍**：推荐 Canvas 绘制游戏区域（网格与元素绘制简单、刷新稳定）；DOM 渲染为备选。取舍理由写入架构契约，A7 实现可二选一，但必须满足同一套可验收行为。
- **输入与节拍**：固定节拍推进；方向输入经合法性校验后生效（禁止瞬时 180° 反向）；结束状态下方向输入不改变游戏状态。
- **状态与计分**：初始方向向右、分数 0；吃食物 +10 并增长；撞墙进入结束阶段并显示最终分数；重开完整重置状态（分数、蛇、食物、方向、阶段）。
- **零依赖约束**：不发起网络请求、不读取本地存储、不上传任何用户数据。

## 五、验收对应（AC1–AC5）

| AC | 可验证口径 |
|---|---|
| AC1 能启动运行 | 现代桌面浏览器直接打开 `index.html` 即可开始；无阻断性脚本错误，可见游戏区域与初始分数 0。 |
| AC2 键盘控制且禁止反向 | 按方向键后，蛇在下一移动节拍沿对应方向移动；与当前前进方向相反的输入被忽略，蛇不会立即 180° 反向。 |
| AC3 吃食物加分 | 蛇头到达食物所在格时分数 +10，蛇身增长，并在空位生成新食物。 |
| AC4 撞墙即结束 | 蛇头越过游戏区域边界时立即结束，显示结束状态与最终分数；之后方向输入不再改变游戏状态。 |
| AC5 重开且分数归零 | 结束状态下执行重开操作后开始新一局，分数显示为 0，蛇回到初始位置与初始方向，可再次正常操作。 |

验收方式：在桌面浏览器中逐项实际操作核对，五项全部满足即视为本版验收通过。

## 八、风险与缓解

- 浏览器差异 → 以现代桌面浏览器为验收环境，只用标准 DOM/Canvas 能力。
- 节拍与输入时序导致「看起来反向」→ 输入在移动节拍生效前校验，并明确禁止瞬时 180° 反向。
- 重开重置不完整 → 重开统一走一个 reset 流程，覆盖分数、蛇身、方向、食物、阶段。
- 单文件体积膨胀 → 本版功能有限，保持结构清晰与注释可读即可，不引入额外依赖。

## 九、质量档位

基础可玩：AC1–AC5 全部通过，规则行为确定、可重复验证；零依赖、可直接打开运行、交付物可被完整审阅。不要求生产级健壮性、跨浏览器兼容矩阵、性能压测、无障碍与视觉设计深度、自动化测试体系。
