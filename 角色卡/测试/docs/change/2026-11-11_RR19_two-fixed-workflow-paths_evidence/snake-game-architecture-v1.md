# 贪吃蛇游戏 · 架构与契约（snake-game v1）

依据提案：`docs/proposals/snake-game-proposal-v1.md`。
依据意图：`docs/product/snake-game-intent-v1.md`。
模块清单：`docs/proposals/snake-game-modules-v1.md`（唯一模块 `snake-game-app`，路径 `index.html`）。

## 一、总体架构

单文件、零依赖、无构建：全部交付物为项目根下 `index.html`，HTML 骨架、样式与脚本均内嵌。文件内部按职责分层组织，**不在文件系统层面拆分模块**，因此不存在跨文件依赖或循环依赖。

```
index.html
├─ <style>        样式与游戏区域布局
├─ HTML 骨架       游戏区域容器、分数显示、结束提示与重开按钮
└─ <script>      游戏配置 / 状态 / 输入 / 循环 / 规则 / 渲染 / 重开
```

## 二、文件内分层

1. **配置与常量层**：网格列数/行数、单元格尺寸、移动节拍（毫秒）、食物分值（本版 10 分）、初始蛇身与初始方向（向右）。
2. **状态层**：游戏阶段（`idle` / `running` / `over`）、蛇身坐标数组、当前方向、待生效方向、食物坐标、分数。
3. **输入层**：监听方向键（上/下/左/右；WASD 可选）与重开操作（按钮/R 键）；将输入转换为「目标方向」并做合法性校验。
4. **循环层**：固定节拍 tick 推进（如 `setInterval` 或基于 `requestAnimationFrame` 的定步长调度）；仅在 `running` 阶段推进。
5. **规则层**：按方向移动蛇头；判断是否撞墙（越界）→ 进入 `over`；判断是否吃到食物 → 分数 +10、增长、生成新食物；不处理撞自身（本版非目标）。
6. **渲染层**：绘制游戏区域网格、蛇、食物、当前分数、结束状态与最终分数。
7. **控制层**：初始化（`idle` → 开始）、结束、重开（完整重置回初始状态并回到可操作状态）。

## 三、渲染取舍

- **推荐：Canvas 2D**。网格与元素绘制简单、刷新稳定、单文件内嵌成本低；适合固定节拍的贪吃蛇。
- **备选：DOM/CSS 网格**。实现同样可行，但需维护单元格节点与更新逻辑，代码量略高。
- 取舍只影响内部实现，不改变对外可验收行为；A7 可二选一，但必须满足本契约与 AC1–AC5。

## 四、状态机

- `idle`：已加载、可开始（或直接开始）；分数 0，蛇与食物处于初始位。
- `running`：按节拍推进，接受方向输入并经校验后生效，处理进食与撞墙。
- `over`：撞墙后进入；停止移动与计分，显示结束状态与最终分数；方向输入不改变游戏状态；仅重开操作可离开该阶段。
- **分数**：`running` 中吃食物 `+10`；`over` 冻结最终分数；重开重置为 0。

状态迁移：`idle → running`（开始/首帧）→ `over`（撞墙）；`over → running`（重开并重置）。

## 五、公开契约（对外可验收行为）

| 契约项 | 约定 |
|---|---|
| 启动 | 浏览器直接打开 `index.html` 即可运行；无阻断性脚本错误；初始分数显示 0。 |
| 移动 | 蛇按固定节拍沿当前方向移动一格。 |
| 方向输入 | 方向键改变方向；与当前方向相反（180°）的输入被忽略；同方向/垂直方向输入生效。 |
| 进食 | 蛇头进入食物格：分数 +10、蛇身增长、食物在未被占据格重新生成。 |
| 撞墙 | 蛇头越出游戏区域边界：立即进入 `over`，显示最终分数，停止移动与计分。 |
| 重开 | 结束状态下通过按钮或 R 键重开：分数归零、蛇回初始位置与方向、食物重新生成、可再次操作。 |
| 数据 | 不读写本地存储、不发网络请求、不采集或上传用户数据。 |

内部数据约定（供实现自洽，不构成额外验收项）：蛇身按头到尾的坐标数组维护；方向用枚举表示；食物坐标为未占据格；配置集中在一处便于调整节拍与分值。

## 六、数据流

```
键盘输入 → 输入层校验（禁止 180° 反向）→ 待生效方向
        → tick 触发 → 更新当前方向 → 计算新蛇头
        → 撞墙判定？ → 是：进入 over，渲染结束与最终分数
                     → 否：进食判定？ → 是：分数 +10、增长、生成食物
                                      → 否：常规移动（去尾/加头）
        → 渲染帧 → 下一 tick
重开操作 → 重置状态（分数/蛇/食物/方向/阶段）→ 可再次操作
```

## 七、依赖方向

- 文件内单向依赖：配置 → 状态 → 输入/循环 → 规则 → 渲染；控制层编排各层。无循环依赖、无外部依赖、无网络调用。
- 模块层面：仅 `snake-game-app` 一个模块，路径 `index.html`；实现角色写集仅限该文件。

## 八、扩展点（本版不实现）

- 移动节拍与分值集中配置，便于后续调参（属变更后事项）。
- 状态机与判定逻辑分层，便于后续加入暂停、障碍物、穿墙等（本版非目标，需立项变更）。
- 渲染层可替换（Canvas ↔ DOM）而不影响规则层。
- 注意：「蛇头撞自身」判定不在本版扩展点承诺内，如需要须走需求变更出新版本。

## 九、验收对应（AC1–AC5）

- **AC1 能启动运行**：打开 `index.html` 即运行，无阻断性错误，可见游戏区域与初始分数 0。
- **AC2 键盘控制且禁止反向**：方向键驱动下一节拍移动；相反方向输入被忽略。
- **AC3 吃食物加分**：进食 +10、增长、生成新食物。
- **AC4 撞墙即结束**：越界立即 `over`，显示最终分数；之后方向输入无效。
- **AC5 重开且分数归零**：重开后分数 0、蛇回初始位置与方向、可再次操作。

验收方式：桌面浏览器逐项实操核对，五项全部满足即通过；默认由内置 verifier 复核，客户按 AC 实操确认。
