# snake-game · A1 产品受理与准备

## 受理结论

- 受理状态：**已受理**
- flowId：`snake-game`
- 客户需求摘要：贪吃蛇游戏，支持键盘控制、计分、重开、边界碰撞（撞墙即结束）。
- 本阶段边界：仅做受理与准备；**不写意图正文、不派 A2、不运行 shell 探测环境、不计算哈希**。

## A2 意图撰写将覆盖的要点

1. **目标用户与场景**：谁玩、在什么场景下玩（需 A2 落实）。
2. **要解决的问题**：做出可玩、可重复开局的贪吃蛇小游戏。
3. **功能范围**：
   - 键盘控制（方向输入）
   - 计分（得分随游戏进程变化）
   - 重开（一局结束后可重新开始）
   - 边界碰撞（撞墙即结束）
   - 运行方式（**待 A2 明确**：浏览器 / 桌面 / 终端等）
4. **非目标**：A2 明确本版不做的内容（如联网对战、排行榜、音效等）。
5. **成功/验收标准**：可操作、可计分、可重开、撞墙即结束，且能被稳定复现与验收。
6. **客户原话与约束**：保留客户需求原话，登记平台/性能/质量等约束。
7. **质量档位**：明确本版质量目标与验收强度（待 A2 与客户对齐）。

## 待明确事项（A2 前缺口）

- 运行方式与目标平台（浏览器 / 桌面 / 终端）尚未明确。
- 键盘按键映射、计分规则细节、重开触发方式（按键/自动）尚未明确。
- 质量档位与验收方式尚未明确。

以上缺口由 A2 在意图中明确；如客户未提供，应由运营/幕僚发卡或转客户澄清，不自行猜测。
