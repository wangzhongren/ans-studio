# 贪吃蛇小游戏 产品意图（v1）

## 客户原话

「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。」

项目为空目录起步，无既有代码与文档。

## 目标与核心玩法

单机、纯前端的贪吃蛇小游戏：蛇在固定棋盘上按节拍移动，玩家用键盘控制方向，吃到食物得分并增长，撞到边界即游戏结束，结束后可重开再来一局。

## 范围（MVP）

- 单机前端小游戏，无后端、无网络。
- 固定尺寸棋盘；蛇按固定节拍自动前进。
- 键盘方向键与等效 WASD 控制转向。
- 食物随机生成；吃到后蛇身增长并加分。
- 实时显示当前分数。
- 撞边界即游戏结束并显示结束状态。
- 游戏结束后可重开，状态复位。

## 非目标

- 多人联机、账号、登录、排行榜。
- 分数/最高分持久化。
- 移动端/触屏适配。
- 音效、皮肤、关卡、难度、暂停。
- 随分数加速等额外玩法。

## 成功/验收标准

1. 键盘控制：方向键/WASD 转向在下一移动节拍生效；180° 反向输入被忽略，不造成自杀式掉头。
2. 计分：初始分数 0 且可见；吃到食物加分并同步显示；未吃食物分数不变。
3. 重开：结束后可重开，蛇、食物、分数全部复位（分数归 0）。
4. 边界碰撞：蛇头越界即结束、停止移动并显示结束状态；结束后方向输入不改变状态。

## 待确认项（供后续澄清）

- 撞墙即结束 vs 允许穿墙（本意图按「撞墙即结束」）。
- 自撞（蛇头撞自身）是否与边界碰撞同一结束口径（本意图未将自撞列为独立验收项）。
- 重开的具体触发方式（按键 / 按钮 / 两者）。
- 是否纳入最高分持久化（当前列为非目标）。
- 食物生成规则、每食物分值、棋盘尺寸与初始蛇长。
