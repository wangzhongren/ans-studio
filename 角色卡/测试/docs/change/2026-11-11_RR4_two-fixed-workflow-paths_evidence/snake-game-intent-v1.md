# 贪吃蛇游戏 产品意图（v1）

## 1. 目标用户与场景

- 目标用户：想在浏览器里快速玩一局经典贪吃蛇的普通用户；具备键盘与桌面浏览器，愿意直接打开本地文件使用。
- 使用场景：用户在本地打开 `index.html`，用方向键或 WASD 操控蛇吃食物刷分；失误撞墙后一键重开继续玩。无需安装、无需联网、无需账号。

## 2. 要解决的问题

客户希望得到一个「开箱即玩」的经典贪吃蛇：键盘可控、吃食物有计分反馈、失败后可立刻重开、撞墙即判负。当前没有该游戏，需要从零交付一个最小但完整可玩的单页版本。

## 3. 范围与非目标

### 3.1 范围（V1 必做）

- 纯前端单页：`HTML + CSS + JavaScript`，单个 `index.html` 入口即可运行，可内联或同级引用资源。
- 游戏本体：网格场地、蛇按固定节拍持续前进、蛇身增长。
- 键盘控制：方向键（↑↓←→）与 WASD 均可控制方向。
- 食物与计分：随机生成食物；吃到后分数增加、蛇变长、生成新食物。
- 失败判定：蛇头越出场地边界即游戏结束。
- 重开：结束后可重开，回到初始状态（初始蛇身、分数清零、食物重新生成）。

### 3.2 非目标（V1 不做）

- 手机触控 / 虚拟摇杆适配。
- 联网对战、房间、匹配。
- 排行榜后端、账号系统、登录、数据持久化。
- 构建打包工具链、后端 API、数据库。
- 多语言、主题皮肤、可调难度/速度等扩展设置。
- 音效与外部美术资源依赖。

## 4. 成功 / 验收标准

验收以「本地浏览器打开 `index.html` 后按固定步骤操作」为方法，逐条机械核验：

| 编号 | 验收项 | 核验方式（可机械执行） |
| --- | --- | --- |
| A1 | 键盘控制移动 | 分别按方向键与 WASD，观察蛇的下一步方向随按键改变并沿该方向前进；连续按不同方向键取最近一次合法方向。 |
| A2 | 吃到食物加分 | 记录分数与蛇长，操控蛇头进入食物格：食物消失、分数增加（增量 > 0）、蛇身长度 +1。 |
| A3 | 重开重置状态 | 对局中或结束后触发「重开」：分数回到初始值 0、蛇身恢复初始长度、食物重新生成于场地内。 |
| A4 | 边界碰撞失败并可重开 | 持续朝一个方向移动直至蛇头越出场地边界：进入游戏结束状态（界面明确显示结束/失败）；随后重开并按 A3 恢复初始状态且可再次操作。 |
| A5 | 本地可运行 | 直接双击打开 `index.html`（无服务器、无网络）即可完成 A1–A4 的验证。 |

全部 A1–A5 通过即视为本版交付验收通过。

## 5. 客户原话与约束

- 客户原话（原文照录）：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）」。
- 约束：纯前端、本地直接打开、无构建步骤、无后端、无网络依赖；不引入客户未要求的额外系统。

## 6. 质量档位

可玩性优先的 MVP 档：

- 核心玩法（移动、方向控制、吃食物计分、边界碰撞失败、重开）稳定可用，无阻断性缺陷。
- 键盘输入响应及时，操作与画面反馈无明显延迟。
- 不要求高保真美术、动画特效、音效、性能基准或多人能力；不要求兼容移动端。

## 7. 待澄清（材料性歧义）

- 本版未收客户对「撞到自身是否也判负」的明确要求：客户原话仅点名「边界碰撞」。V1 按最小范围仅强制边界碰撞判负；自身碰撞行为留待后续版本由客户确认后确定，不作为本版验收项。
