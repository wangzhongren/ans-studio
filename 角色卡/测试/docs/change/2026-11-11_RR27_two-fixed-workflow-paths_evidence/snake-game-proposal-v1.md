# 贪吃蛇游戏 · 产品提案 v1

## 1. 依据

本提案依据客户已确认的产品意图 `docs/product/snake-game-intent-v1.md`（intentId: snake-game；客户原话：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）」），并遵循意图入口 `docs/intents/snake-game.md`。

## 2. 目标与范围

- 单机单人、离线可玩的贪吃蛇小游戏。
- 键盘方向键控制蛇的移动方向；食物随机生成，吃到食物 +1 分并实时显示分数。
- 撞墙（边界）立即结束游戏，停止移动与计分。
- 结束后可重开：分数归零、蛇回到初始位置与长度、食物重新生成、结束态清除。
- 交付形态：纯静态单页网页（HTML / CSS / 原生 JavaScript），无构建步骤与外部依赖，用浏览器打开 `index.html` 即可本地运行。

## 3. 验收标准

1. 启动后进入初始状态，蛇可随键盘方向键移动并改变方向。
2. 吃到食物分数 +1，且分数在界面上实时可见。
3. 撞墙（边界）立即结束游戏，停止移动与计分，进入结束态。
4. 结束后可按约定方式重开（R 键或界面「重开」按钮）；重开后分数归零、蛇回到初始位置与长度、食物重新生成、结束态清除，且可再次正常操作。
5. 成品可在本地按约定形态启动（浏览器打开 `index.html`），完整走通「移动 — 吃食物加分 — 撞墙结束 — 重开复位」流程。

## 4. 默认假设（待客户确认）

以下复述产品意图 v1 的 9 条默认假设：

1. **撞自身判定**：蛇头撞到自身（蛇身）也判定为游戏结束，与撞墙同为结束条件。
2. **180° 反向**：不允许直接反方向移动；与当前方向相反的按键输入被忽略。
3. **速度/难度**：默认固定匀速移动，不随分数加速；不设难度档位。
4. **食物与计分**：同一时刻仅一个食物，随机生成在空白格；每个食物默认 +1 分，分数只增不减。
5. **边界行为**：撞到边界即结束，不做穿墙。
6. **重开方式**：结束后以按键（R）或界面按钮触发重开；重开即重置分数、蛇、食物与结束态，不保留历史成绩。
7. **交付形态与技术栈**：浏览器网页版（纯静态单页、可本地打开运行），不引入构建工具与前端框架。
8. **界面细节**：画布尺寸、网格大小、配色与字体等按常规默认实现。
9. **附加功能**：暂停、最高分记录、音效等默认不做，列为非目标；如客户另行提出再评估。

## 6. 非目标

- 不做多人/联机对战；不做排行榜、账号、云端存档等在线功能。
- 不做暂停、音效、皮肤/关卡系统。
- 不引入服务端、数据库、构建工具链或第三方运行时。

## 7. 风险与待确认

- 重开触发方式（R 键 + 界面按钮）、画布/网格/配色均为默认实现，待客户确认；如客户指定，出 proposal 新版本。
- 为保证 `file://` 直接打开可运行，脚本使用经典 `<script>` 而非 ES module；如后续需要模块化，需本地静态服务器并另行确认（届时出架构新版本）。
