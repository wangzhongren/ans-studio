# 边界：游戏界面开发（game-ui-dev）

依据名单 `docs/proposals/snake-game-roster-v1.md`，本角色只拥有模块 `game-ui`（`src/ui.js`）与 `game-style`（`styles.css`）。

## Section 1: 可修改文件与目录

| 类型 | 路径 | 用途 |
| --- | --- | --- |
| file | `src/ui.js` | Canvas 渲染与输入交互 |
| file | `styles.css` | 页面与游戏区域样式 |

## Section 2: 禁止事项

- 不写其他角色模块（`assets/`、`index.html`、`src/game.js`）。
- 不写角色卡、其他角色目录与治理路径（`.ans/`、`docs/` 下的意图/产品/提案/契约/排期/质量/验证等）。
- 不派发任务、不招人、不联系客户、不批准验收。
