intentId: snake-game
flowId: snake-game
goal: |
  交付一个可玩的单机单人贪吃蛇小游戏：键盘方向键改变蛇的移动方向，吃到食物加分并显示分数，撞到边界（墙）即游戏结束，结束后可重开且分数与游戏状态复位。
scope: |
  1. 单机单人贪吃蛇；键盘方向键控制蛇的移动方向。
  2. 食物随机生成，吃到食物加分，并在界面上显示当前分数。
  3. 撞墙（边界）即游戏结束。
  4. 结束后可重开；重开后分数归零，蛇与食物复位。
  5. 交付一个可在本地运行、可玩的完整小游戏成品。
acceptance: |
  1. 启动后进入初始状态，蛇可随键盘方向键移动并改变方向。
  2. 吃到食物分数增加，且分数在界面上实时可见。
  3. 撞墙（边界）立即结束游戏，停止移动与计分，进入结束态。
  4. 结束后可按约定方式重开；重开后分数归零、蛇回到初始位置与长度、食物重新生成、结束态清除，且可再次正常操作。
  5. 成品可按约定交付形态在本地启动，并完整走通「移动—吃食物加分—撞墙结束—重开复位」流程。
nonGoals: |
  1. 不做多人/联机对战。
  2. 不做排行榜、账号、云端存档等在线功能。
  3. 不做暂停、音效、皮肤/关卡系统等未被要求的功能（如需要另行提出）。
  4. 不提前锁定未经客户确认的技术栈或引入超出小游戏范围的能力。
constraints: |
  1. 单机单人、离线可玩；键盘方向键为主要操作方式。
  2. 不得擅自扩大范围：多人、联网、排行榜等一律不做。
  3. 项目为空目录、新建项目路径 A；环境事实以应用记录为准（当前空目录、非 Git 仓库）。
  4. 客户未明示的细节按合理默认执行，并在本文档中显式标注为「待客户确认的假设」。
