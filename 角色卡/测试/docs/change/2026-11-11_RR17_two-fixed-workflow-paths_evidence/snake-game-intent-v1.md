# 产品意图：snake-game（贪吃蛇游戏）

## 目标（goal）

交付一个可在本机直接用键盘操作的经典贪吃蛇游戏：用方向键控制蛇的移动，吃到食物即加分并实时可见，蛇头撞到游戏区域边界即游戏结束（失败），游戏结束或进行中均可重新开始且状态完整重置。

## 目标用户与场景

- 目标用户：希望即开即玩、无需学习成本的单机休闲玩家。
- 使用场景：在桌面/本地环境中短暂游玩，单局制；通过方向键操作，观察分数变化，撞墙失败后按重开继续。
- 运行平台、启动方式与可验证条件：待应用事实确认，由后续阶段与客户澄清后确定；本意图不预先锁定。

## 要解决的问题

提供一个零门槛、可快速上手并反复游玩的经典贪吃蛇体验，满足四项核心诉求：键盘控制移动、吃到食物计分、失败/进行中可重开、边界碰撞即结束。

## 范围（scope）

本期必做范围（对应客户原话四项）：

1. 键盘控制
   - 控制方案：方向键 ↑ ↓ ← → 各对应上、下、左、右移动方向，为唯一标准控制方案。
   - 蛇按当前方向持续前进；按方向键改变前进方向（不允许 180° 即时反向）。
2. 计分
   - 初始分数为 0，界面实时显示当前分数。
   - 每吃到一个食物固定加 1 分。
3. 重开
   - 游戏进行中或游戏结束后，按 R 键重新开始。
   - 重开后分数归零、蛇回到初始长度与初始位置、速度恢复初始值、食物重新随机放置。
4. 边界碰撞
   - 蛇头触碰游戏区域边界即游戏结束，判为失败，显示结束状态。
5. 支撑性最小范围（为四项核心可玩所必需）
   - 食物随机出现在游戏区域内的空位；吃到食物后蛇身长度增加 1。
   - 界面需可见游戏区域、蛇、食物与当前分数。

## 非目标（nonGoals）

本期明确不做：

- 联网、多人对战或排行榜。
- 移动端触控操作。
- 音效与背景音乐。
- 账号体系与跨局最高分持久化存储。
- 暂停、难度选择、加速档位与关卡系统。
- WASD 或自定义键位方案。
- 蛇自撞失败判定（本期不作为必做项）。
- 穿墙模式（撞墙一律结束）。

## 成功与验收标准（acceptance）

逐项可观察、可操作，供独立核验：

- AC1（键盘控制）：进入游戏后，按 ↑ / ↓ / ← / → 可分别使蛇的行进方向变为上 / 下 / 左 / 右；方向改变在画面上可观察到；不按方向键时蛇按当前方向持续前进。
- AC2（计分）：游戏开始时分数显示为 0；控制蛇吃到 1 个食物后分数显示为 1；再吃到 1 个食物后分数显示为 2；分数变化在吃到食物后立即可见。
- AC3（重开）：游戏进行中按 R 键可立即重新开始；游戏结束后按 R 键亦可重新开始；重开后分数显示为 0、蛇回到初始长度与初始位置、食物重新出现，且方向键可再次正常控制。
- AC4（边界碰撞）：控制蛇头向任一方向持续移动直至触碰游戏区域边界时，游戏立即结束并显示失败/结束状态；结束后蛇不再随方向键移动（按 R 重开除外）。
- AC5（食物与成长，支撑项）：食物出现在游戏区域内的空位；吃到食物后蛇身长度增加 1，且新食物再次出现。

## 客户原话与约束

客户原话（逐字带入，未改写）：

> 做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。

约束：

- 以上四项为客户明确诉求，均为本期必做；不得以扩展功能替代或弱化。
- 单机、本地、无需联网即可游玩。
- 运行平台与启动方式待应用事实确认；不含环境探测结论。

## 质量档位

可玩级（playable）：四项核心功能完整可用、键盘操作响应及时无明显延迟、界面元素（蛇、食物、分数、结束状态）清晰可辨、重开与失败判定行为稳定；不要求美术打磨、音效、动画特效或性能优化。
