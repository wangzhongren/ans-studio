## 一、方案摘要

交付一个**单页静态网页版贪吃蛇**：直接双击 `index.html` 即可游玩，无构建、无后端、无联网、无第三方依赖。使用经典 `<script src>` 顺序加载（不使用 ES module，避免 `file://` 协议下的模块加载限制），Canvas 2D 绘制，固定节拍网格步进。

核心行为严格对齐意图 v1：
- 方向键（上/下/左/右）控制走向，持续按固定节拍移动；180° 反向输入被忽略（不原地调头）。
- 每吃到一个食物：食物消失、分数 +1、蛇身增长、分数显示实时更新；初始分数 0；不随分数加速。
- 蛇头下一格越出网格边界即本局立即结束（game over），不穿墙、不阻止移动；结束后停止移动，直到重开。
- 重开：分数归 0、蛇复位到初始位置与长度、食物重新生成、输入方向复位，可立即继续操作。

## 二、运行形态与技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 运行形态 | 单页静态网页（HTML/CSS/JS） | 与意图 v1 默认假设一致；双击可玩 |
| 脚本加载 | 经典 `<script src>` 顺序加载，IIFE + 命名空间 `window.SnakeGame` | `file://` 下 ES module 常被 CORS 拒绝；无需构建 |
| 渲染 | Canvas 2D | 网格绘制简单、无外部依赖、性能足够 |
| 依赖 | 零第三方依赖、零外部素材、零网络请求 | 离线可用；避免下载审批 |
| 存储 | 无持久化（不写 localStorage） | 意图 non-goal：不做存档/排行榜 |

## 三、模块划分（摘要，权威见模块清单）

| 模块 id | 路径 | 职责 |
| --- | --- | --- |
| `entry-page` | `index.html` | DOM 结构（canvas/分数/结束提示/重开按钮）与脚本加载顺序 |
| `game-core` | `src/game.js` | 状态机、步进、方向与反向拦截、计分增长、越界判定、重开复位（纯逻辑） |
| `game-render` | `src/render.js` | Canvas 绘制、分数/结束 UI、固定 tick 主循环、重开按钮交互 |
| `game-input` | `src/input.js` | 方向键监听与 preventDefault、方向意图传递、重开按键 |
| `game-style` | `src/style.css` | 页面布局与可读样式 |

分层与依赖方向：`entry-page` 负责装配 → `game-input`/`game-render` 依赖 `game-core` 的公开 API → `game-core` 不依赖任何 DOM/渲染/输入。详见 `docs/contracts/snake-game-architecture-v1.md`。

## 四、关键实现口径（在契约中冻结，不改变意图行为）

1. **网格与节拍**：20×20 网格，固定 tick 130ms；蛇按格步进，不插值。
2. **初始状态**：蛇长 3，水平居中、方向向右，分数 0；食物在非蛇身空格中随机生成。
3. **方向规则**：仅接受上/下/左/右；与“当前生效方向”相反的输入被忽略；同一 tick 内多次按键只保留最后一个合法方向，避免连续按键绕过反向限制。
4. **越界判定**：计算下一格蛇头坐标，若超出 `[0,20)×[0,20)` 即立即置 `over`，不穿墙、不夹取。
5. **计分与食物**：吃到食物后分数 +1、蛇增长 1 节、食物在同一 tick 内重新生成于非蛇身空格；分数字段实时更新。
6. **结束态**：`over` 后停止 tick、忽略方向输入，界面显示最终分数与重开按钮（同时支持重开按键）。
7. **重开**：分数=0、蛇复位初始位置与长度、方向复位向右、食物重生成、清空待处理方向与计时器，立即进入 `playing`。
8. **满盘边界**：若棋盘无空格可生成食物（低频），不崩溃、不挂起；按契约以确定性方式结束本局并提示（该情形不作为验收项）。

## 五、验收映射（AC1–AC4）

| 意图条目 | 实现落点 | 验收方法（现代桌面浏览器双击入口页） |
| --- | --- | --- |
| AC1 键盘控制 | `game-input` + `game-core` 方向规则 | 按四个方向键观察走向改变并持续移动；朝当前方向按反方向键，蛇不调头 |
| AC2 计分 | `game-core` 计分/增长 + `game-render` 分数显示 | 初始 0；吃食物后食物消失、分数 +1、蛇变长、显示同步 |
| AC3 重开 | `game-render` 重开交互 + `game-core` reset | 撞墙后显示最终分数与重开入口；重开后分数 0、蛇复位、食物重生成、可立即操作 |
| AC4 边界碰撞 | `game-core` 越界判定 + 状态机 | 蛇头贴边后继续前进，越界瞬间 game over；不穿墙；结束后无法继续移动 |

质量档位沿用意图 v1：最小可玩版，四项功能完整、无阻塞性缺陷、操作响应无明显延迟；不要求美术/音效/跨浏览器全覆盖。

## 七、风险与缓解

| 风险 | 缓解 |
| --- | --- |
| `file://` 下 ES module 加载失败 | 使用经典脚本顺序加载；契约固定加载顺序 |
| 方向键默认滚动页面 | 输入层对方向键 `preventDefault` |
| 初始蛇长过短导致反向不可观测 | 固定初始长度 3 |
| 重开后残留方向/计时器导致瞬间反向或撞墙 | reset 清空待处理方向并重启单一 tick 计时器 |
| 食物生成在蛇身上 | 仅在非蛇身空格中随机；满盘时确定性处理 |
| 结束后仍可移动导致 AC4 判定失败 | `over` 状态停止 tick 并忽略方向输入 |

- 任何需求变更走意图新版本；方案/模块/名单/契约变更各自出新版本（`-vN`），不原地修改旧版。
