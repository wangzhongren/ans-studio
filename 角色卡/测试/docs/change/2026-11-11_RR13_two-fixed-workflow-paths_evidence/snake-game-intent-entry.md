intentId: snake-game-intent

goal: |
  交付一个可直接在浏览器中打开即玩的贪吃蛇小游戏：键盘控制蛇移动、吃到食物计分、撞边界（及撞自身）即失败并结算、结束后可一键重开；单页网页版、零第三方依赖、零构建步骤、断网可玩。
scope: |
  单页网页版贪吃蛇 MVP：
  1) 纯前端单页网页版（HTML + CSS + JS + Canvas），零第三方依赖、零构建步骤，双击 HTML 以 file:// 直接打开即玩，不打包桌面可执行。
  2) 控制：方向键（↑↓←→）与 WASD 四方向；禁止 180° 直接掉头；空格暂停/继续（默认提供）。
  3) 计分：每个食物固定 +1，游戏过程中实时可见；最高分用 localStorage 仅本地保存，不联网。
  4) 失败与结算：撞网格边界即失败，撞自身亦判失败；失败后立即冻结移动并显示结算（本局得分 + 最高分），提供「重开」按钮与 R / Enter 快捷键。
  5) 重开：分数、蛇身长度与位置、食物、速度全部复位，可直接继续下一局。
  6) 场地与速度：固定网格场地；初始固定速度，随得分按固定步长加速并设下限封顶；逻辑判定边界与可见场地边界一致。
  7) 食物：同一时刻场上仅一个食物，只生成在空白格，不落在蛇身上。
acceptance: |
  - AC-1 方向控制生效：按 ↑/↓/←/→ 或 W/A/S/D，蛇按对应方向每步前进一格，同一时刻只有最后一次合法方向生效；蛇向右移动时按左不生效，不反向、不穿身自撞。
  - AC-2 计分实时递增：吃到食物后当前分数立即 +1 且游戏进行中可见；食物消失并在其他空白格重生，新食物不落在蛇身上。
  - AC-3 撞边界即失败结算：越过最后一格边界时蛇立即停止并显示结算（本局得分与最高分），不穿墙、不在对侧出现、不再响应移动、分数不再变化。
  - AC-4 撞自身即失败：蛇身成环撞到自身时进入与 AC-3 相同的失败结算态。
  - AC-5 重开完全复位：结算态点击「重开」或按 R / Enter，分数归 0、蛇回初始长度与位置、食物重新生成、速度回初始档、恢复可控；连续多局一致无残留。
  - AC-6 零依赖离线可玩：断网状态下双击打开 HTML，控制/计分/失败结算/重开全部可用，无网络依赖导致的白屏或报错，无需安装依赖或构建。
  - AC-7 最高分本地保留（条件项，随 M2 确认）：结算显示历史最高分，刷新后仍在，重开不清空，全程无网络请求。
  - AC-8 暂停（条件项，随 M5 确认）：空格暂停时蛇停止移动、分数不变；再按恢复，暂停/恢复不改变蛇身与食物状态。

  - 音效与美术资源（仅最小可用画风）。

  - 关卡编辑器、皮肤系统、成就系统、难度曲线编辑等增强项。
  - 桌面可执行程序打包。
  - 跨浏览器/多端兼容矩阵打磨（默认仅客户本机现代桌面浏览器）。
constraints: |
  - 客户原话：「做一个贪吃蛇游戏，要求键盘控制、计分、重开、边界碰撞（撞边界即失败/结算）。」四项点名能力为必含项。
  - 意图中的默认值（运行形态、场地尺寸、速度与加速规则、最高分保存、快捷键、结算形态、界面语言等）均为产品侧建议默认值，客户尚未逐项裁定；确认以幕僚呈递的意图确认卡为准，未确认前不得当作已批准。
  - 撞边界必须判为失败/结算，不得穿墙重生或静默继续；逻辑边界必须与可见场地边界一致。
  - 单页、零第三方依赖、零构建步骤、可离线运行（建议默认值，随运行形态一并待确认）。

## 质量档位

最小可用但完整可玩（功能型 MVP）：四项点名能力真实可用、失败与重开闭环正确、无卡死与状态残留；不追求美术精修、音效、动画、多端适配。
