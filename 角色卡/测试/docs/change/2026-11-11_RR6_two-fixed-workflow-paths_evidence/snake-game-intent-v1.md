# 产品意图 · snake-game v1

## 客户原话

> 做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。

## 目标用户与场景

- 目标用户：希望在桌面浏览器中快速打开、用键盘玩一局经典贪吃蛇的普通用户（单人、离线、无需安装）。
- 使用场景：双击本地 HTML 文件即可开始；用方向键或 WASD 控制蛇移动，吃到食物得分，撞墙或撞到自己游戏结束，按 R 键或按钮重开再玩一局；最高分在本机跨会话保留。

## 要解决的问题

提供一个小而完整、开箱即玩的单机贪吃蛇：键盘操控、看得见的计分与最高分、失败后一键重开、清晰的边界与自身碰撞规则，全程无需网络、构建或外部依赖。

## 范围内功能细节

1. **键盘控制**
   - 方向键 ↑↓←→ 与 WASD 并存，任意时刻两套键均可使用。
   - 禁止 180° 直接反向：与当前前进方向相反的输入不生效，蛇不会因此立即掉头撞自身。
2. **计分与最高分**
   - 每吃到一个食物：蛇长 +1，当前分数 +10。
   - 顶部 HUD 同时显示「当前分数」与「最高分」，随操作实时更新。
   - 最高分写入浏览器本地存储，重开、刷新、重新打开页面后仍保留。
3. **重开**
   - 游戏结束后，可按 R 键或点击「重开」按钮重开。
   - 重开后当前分数清零、蛇回到初始位置与初始长度；最高分保留。
4. **边界碰撞与规则**
   - 撞墙即游戏结束，蛇不穿墙、不四边环绕。
   - 蛇头与自身身体碰撞即游戏结束。
   - 固定 20×20 网格；蛇以恒定速度移动，不随分数加速。
5. **运行形态**
   - 单页静态网页（HTML + Canvas + 原生 JavaScript），零构建、零外部依赖，file:// 双击即可离线打开；目标现代 Chrome/Edge 桌面。

## 非目标

移动端触控/响应式、暂停、音效、主题皮肤、难度选择、排行榜、联机、后端/账号/网络存储、构建工具与外部依赖；本阶段不写实现代码与方案/名单/契约。

## 可核验验收清单

1. 方向键与 WASD 均可控制蛇移动；180° 直接反向输入不生效。
2. 吃到食物后蛇长 +1、当前分数 +10，顶部 HUD 实时显示当前分数与最高分。
3. 撞墙即游戏结束，且不穿墙、不环绕。
4. 蛇头与自身身体碰撞即游戏结束。
5. 游戏结束后按 R 键或点击「重开」按钮可重开，当前分数清零、蛇重置、可继续操作。
6. 重开后最高分保留；刷新或重新打开页面后最高分仍保留。
7. file:// 双击离线可打开，无构建、无网络、无外部依赖，在目标现代浏览器可完整游玩。

## 边界采纳与调整说明

- 采纳 A1 建议：方向键+WASD 并存、禁止 180° 反向、每食物 +10、顶部 HUD 当前分/最高分、最高分本地持久化、R 键+按钮重开并保留最高分、撞墙即结束（非穿墙）、自身碰撞结束、20×20 网格恒定速度、单页静态网页离线可开。
- 调整 1：「暂停」由 A1 的「可选」调整为非目标。理由：客户原话四项功能未含暂停，为保持最小可验收范围；如客户需要可在 v2 增补。
- 调整 2：不纳入移动端触控与开始/难度选择等界面扩展，理由同上（需求明确为键盘控制、单机小游戏）。
- 上述边界建议均为 A1 建议稿，正式生效以意图确认门（A3）客户确认为准；文档不主张这些默认项已获客户确认。

## 质量档位

演示/可玩原型级：功能完整、规则清晰、可手工操作验收，代码可读、无外部依赖；不追求美术、性能调优或多端适配。
