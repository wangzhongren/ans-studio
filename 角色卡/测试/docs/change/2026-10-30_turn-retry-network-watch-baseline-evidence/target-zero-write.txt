## Method
- Read-only metadata snapshots before/after the baseline run: path|size|mtime for every file

- `jinyong-rogue-2d`: before/after metadata diff = only the snapshot header line (timestamps); zero file entries changed.
- `Downloads/test`: before/after differs in 178 lines. All differences are under the live application's own runtime
  and work products (`.ans/sessions/**`, `.ans/state/**`, `docs/`, `src/`, `tests/`, `node_modules/.vite/**`), with
  mtimes advancing continuously during the window (e.g. 19:48 before the baseline, 19:55 after). This is external
  activity: a running ANS session is actively writing to that project throughout the window (session replay logs grow
  by hundreds of KB; its agents write project source/docs). It is not caused by this baseline.
- Attribution (path isolation, not equality):
  - `grep -rl "Downloads/test" test/` => 0 files; the regression suite never references the target.
  - `grep -al "Downloads/test" <all baseline logs>` => 0 matches; no baseline command targeted the path.
  - Full suite runs in the worktree with `%TEMP%` fixtures; real-Electron E2E used
    `ANS_E2E_PROJECT=<worktree root>` and `ANS_E2E_OUTDIR=<evidence dir>` (loopback/temp fixtures only).
- Conclusion: this baseline caused zero writes to either target project. The observed `Downloads/test` changes are
  external live-run activity and are recorded for transparency only.
