# 边界：游戏实现者（game-implementer）

## Section 1: 可修改文件与目录

| 类型 | 路径 | 用途 |
| --- | --- | --- |
| directory | `src/core/` | 游戏核心规则与状态机（game-core） |
| directory | `src/input/` | 键盘输入控制（input-controller） |
| directory | `src/render/` | 画面渲染与状态展示（renderer） |
| directory | `src/app/` | 主循环与装配调度（game-shell） |
