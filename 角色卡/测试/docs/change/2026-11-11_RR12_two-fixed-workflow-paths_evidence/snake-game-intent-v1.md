# 贪吃蛇游戏（snake-game）产品意图 v1

## 1. 背景与目标用户

本意图来自客户明确诉求：新建一个贪吃蛇游戏，具备键盘控制、计分、重开、边界碰撞（撞墙结束）四项核心能力。

- 目标用户：希望在本地单机环境下进行休闲小游戏游玩的终端用户。
- 使用场景：用户在本地打开游戏，用键盘控制蛇移动、吃食物累积分数，撞击边界后本局结束并可立即重开继续游玩。

## 2. 要解决的问题

客户需要一个规则完整、可独立游玩的经典贪吃蛇小游戏：操作可预期（键盘方向控制）、进度可见（分数显示并随进食增长）、失败可复盘并快速再来（撞墙结束 + 重开整局重置）。当前尚无该游戏，需从零交付。

## 3. 范围

### 3.1 在范围内

1. **键盘方向控制**：方向键与 WASD 均可控制蛇的移动方向。
2. **吃食物计分与分数显示**：界面显示分数，吃到食物后分数增加。
3. **重开**：一局结束后可整局重置并继续游玩。
4. **边界碰撞**：蛇撞到场地边界（撞墙）时本局立即结束。

### 3.2 不在范围内

- 联网对战、多人同局、排行榜、账号/登录体系。
- 服务端能力、数据持久化、云端存档。
- 移动端触屏/手势控制及专门移动端适配。
- 跨局最高分、音效、暂停/继续、难度/等级、皮肤主题等客户未提出的增值功能。
- 具体技术选型、框架、构建与交付形态（留待下游方案阶段决定）。

## 4. 验收标准

| 编号 | 验收标准 | 判定口径 |
| --- | --- | --- |
| A1 | 键盘控制蛇移动 | 方向键与 WASD 均可改变方向，蛇按方向连续移动，无需鼠标/其他输入。 |
| A2 | 计分显示并随进食增加 | 界面可见分数；吃到食物后分数增加，未进食时不变。 |
| A3 | 重开整局重置并可继续玩 | 结束后可重开，蛇/分数/食物等状态回到初始值，且可立即继续游玩。 |
| A4 | 撞墙即结束 | 蛇头越出边界时本局立即结束，并有可观察的结束反馈。 |

## 5. 质量档位与约束

- 质量定位：可交付、可独立游玩的小游戏（原型级→可用级之间，最终档位由方案与验收阶段确认）。
- 运行约束：单机本地运行，不依赖网络或后端服务。
- 输入约束：键盘输入需同时支持方向键与 WASD。
- 未决细节（计分增量、重开触发方式、结束反馈形式、场地与速度参数等）留给下游方案阶段在符合本意图验收标准的前提下确定。

## 6. 客户原话与假设

- 客户原话（要点）：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）」。
- 合理假设（未替客户做最终决定，供后续确认）：
  - 假设游戏为单机本地运行，无需联网与服务端。
  - 假设「撞墙结束」指蛇头越出可视场地边界即结束；蛇自撞等客户未提及的规则不作为本意图强制项。
  - 假设重开后分数清零、状态回到初始，符合「整局重置」的通常理解。
  - 假设技术选型与交付形态由下游方案阶段决定，本意图不作锁定。
