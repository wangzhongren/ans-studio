# snake-game 产品意图 v1

## 1. 客户原话（逐字）

> 做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）

## 2. 目标用户与场景

- 目标用户：本地单人玩家（终端用户）。
- 使用场景：桌面/本机短时休闲游玩，以键盘为主要输入设备，离线进行。
- 核心体验：一局「移动 → 吃食物 → 得分 → 撞边界结束 → 重开」的完整可玩循环。

## 3. 要解决的问题

客户需要一个简单、直接可玩的贪吃蛇小游戏，用于休闲娱乐。当前诉求聚焦最小可玩闭环：能用手控制方向、能感知得分、失败后有明确结束并可以马上再来一局；不追求联网、社交或长期养成。

## 4. 范围（本期）

1. **键盘方向控制**：使用方向键控制蛇在四个方向（上/下/左/右）移动；不允许 180° 反向掉头（例如当前向右移动时，按左方向不生效，不因反向输入直接判负）。
2. **实时计分**：蛇吃到食物时加分，计分规则为**每吃到一颗食物固定 +1 分**；当前分数在游戏过程中实时可见、随吃食物即时更新。
3. **撞边界判负**：蛇头到达或越过场地边界即本局失败/游戏结束，蛇停止移动并进入结束状态。
4. **结束可重开**：游戏结束后玩家可执行重开操作开启新一局；重开后蛇身回到初始位置与初始长度、分数重置为 0，游戏回到可玩的初始态（重开的具体按键/按钮形式由实现决定，不改变本验收口径）。
5. 上述四项要素须在同一局游戏中同时成立，并可连续重复游玩多局。

## 5. 非目标（本期不做）

- 联网对战、多人同玩。
- 排行榜、账号体系、社交分享。
- **撞自身（蛇头撞到自身身体）判负**：客户原话未要求，本期不纳入验收范围；如后续需要，通过新版本意图变更补充。
- 暂停/继续功能。
- 随分数加速、难度递增、限时挑战等玩法扩展。
- 穿墙（边界环绕）规则；本期边界即撞即死。
- 移动端触摸操作。
- 音效、美术/皮肤等表现层打磨。
- 最高分记录、本地存档与跨会话持久化。

## 6. 成功与验收标准

- **AC1 四方向控制**：按上/下/左/右方向键，蛇按对应方向移动；当前向右移动时按左键不会生效，且不会因该输入导致游戏结束。
- **AC2 实时计分**：新开一局分数为 0；每吃到一颗食物分数 +1，且界面显示的当前分数随之即时更新。
- **AC3 边界判负**：蛇头到达或越过场地边界时，本局立即结束（蛇停止移动，呈现明确的游戏结束状态）。
- **AC4 重开重置**：游戏结束后执行重开，蛇身回到初始位置与初始长度，分数归零，游戏进入可继续操作的初始可玩状态。
- **AC5 完整可玩循环**：可在一局内完整走通「移动 → 吃食物得分 → 撞边界结束 → 重开再玩」，并可连续重复多局而不阻断。

## 7. 质量档位

本期质量档位为**功能可玩级 MVP（内部验证/演示档）**：以四项核心要素正确、可连续游玩为标准；不含正式发行级的音效、美术、性能与兼容性打磨。若客户期望正式发行级体验，需通过后续版本意图升级另行约定。

## 8. 约束与假设

- 遵循客户原话四项要素作为最低范围，不额外扩大玩法。
- 本地单人、键盘输入、离线运行，不依赖网络、账号或外部服务。
- 撞自身、暂停、加速、穿墙等未在客户原话中出现的玩法，均按第 5 节处理，不默认加入。
- 本意图不规定实现技术方案；界面形态、键位映射细节等由后续实现阶段在不改变验收口径的前提下决定。
