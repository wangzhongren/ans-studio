# snake-game A1 受理/准备说明

> 性质：A1 准备说明（初步理解与待澄清项），**不是正式产品意图**，不构成 A2 意图正文、不构成版本，不作为验收依据。
> 正式意图（docs/product/snake-game-intent-v1.md）由 A2 任务另行撰写并升版。

- flowId: snake-game
- 客户目标（原文要点）：做一个贪吃蛇游戏，必须含键盘控制、计分、重开、边界碰撞（撞边界即结束/判定失败），在项目根目录新建实现。
- 本阶段结论：**受理，可进入 A2**（存在次要待澄清项，均可在意图撰写时以明确默认值处理，不阻塞 A2）。

## 1. 初步理解

| 要素 | 初步理解 |
| --- | --- |
| 目标用户与场景 | 终端/本地桌面单人玩家，打开即玩、无需登录的最小可玩贪吃蛇。 |
| 交付形态 | 在项目根目录新建实现（客户端可运行的游戏本体 + 启动说明）。具体技术栈不在产品意图中限定，由方案决定。 |
| 核心功能 | 键盘控制移动；吃食物计分；游戏结束后可重开；撞边界立即结束（判定失败），**不是穿墙**。 |
| 质量档位初读 | 以"可玩、功能齐全、稳定无崩溃"为主，美术/音效不作硬性要求。 |

## 2. 成功标准初读（待 A2 复核，不扩写为新需求）

1. 可用键盘控制蛇方向移动（方向键或 WASD，操作方式留待意图确认）。
2. 吃到食物后分数增加并可读地展示（加分规则留待意图明确）。
3. 游戏结束（失败）后可重新开始一局。
4. 蛇头撞到边界立即结束并判定失败，而非穿墙/环绕。

## 3. 待澄清项清单

| # | 待澄清项 | 影响 | 建议默认（供 A2/客户确认） |
| --- | --- | --- | --- |
| Q1 | 控制方式：方向键 / WASD / 两者皆可 | 验收标准表述 | 两者皆可，作为默认。 |
| Q2 | 计分规则：每个食物固定加分？是否随长度递增？ | 计分验收标准 | 每个食物固定 +1（或固定分值），默认不再细分难度。 |
| Q3 | 结束条件是否仅边界碰撞，还是也含撞自身 | 失败判定范围 | 客户已明确边界碰撞必定结束；自身碰撞按常规默认也结束，需确认是否纳入。 |
| Q4 | 重开触发方式：结束界面按键 / 自动重开 | 交互验收 | 结束后按指定键（如空格/回车）重新开始。 |
| Q5 | 运行方式与技术栈（浏览器 / 终端 / 桌面） | 只在方案层决定，不影响意图 | 由方案阶段确定，不写入意图。 |
| Q6 | 初始速度与是否加速 | 可玩性，非硬性 | 初读可不做加速；如需纳入需客户确认。 |
| Q7 | 是否需要暂停/最高分/移动端触控 | 范围边界 | 初读列为非目标（超出客户目标）。 |

## 4. 边界与不做（初读，供 A2 确认非目标）

- 不做移动端触控、多人对战、联网排行、音效与美术资源（除非客户追加）。
- 不在 A1 写实现代码、不写正式意图正文、不推进 A2。
