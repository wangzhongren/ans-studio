# snake-game 提案（v1）

意图依据：`docs/product/snake-game-intent-v1.md`（intentId=snake-game，version=1，A3 客户本人 confirm）。

## 1. 技术选型

- **纯前端 HTML/CSS/JS 单页实现**：无构建工具、无打包器、无第三方库、无 npm 依赖、无网络请求。
- 脚本使用**经典 `<script>` 标签（非 ES module）**，保证双击 `index.html`（`file://`）即可直接游玩；也可经任意本地静态服务访问。
- 渲染使用 Canvas 2D；游戏逻辑与渲染分离在 `src/game.js` 内以职责分区组织（状态、输入、步进、渲染），`src/styles.css` 负责页面与 HUD 样式。
- 不引入框架（React/Vue 等）、不引入后端、不做 localStorage 持久化。

## 2. 运行方式与文件结构

```
index.html      # 页面入口：标题、分数显示、画布、操作说明、结束/重开遮罩
src/game.js     # 游戏状态机 + 输入 + 步进 + 食物 + 碰撞 + 重开 + 渲染
src/styles.css  # 页面布局与 HUD/遮罩样式
```

- 启动：双击 `index.html`，或在项目根目录运行本地静态服务器后访问。
- 无启动参数、无环境变量、无安装步骤。

## 3. 游戏机制

- 游戏区域为固定网格（默认 20×20，单元格 20px，画布 400×400）；坐标系原点在左上，x 向右、y 向下。
- 初始蛇长 3 格，位于区域中部，初始方向向右；游戏开始后按固定步长持续移动。
- 固定步长推进（默认约 120ms/步，`setInterval` 驱动），不随分数加速（难度递进属非目标）。
- 食物随机生成在**未被蛇身占用的空格**；每次进食后重新生成。
- 吃到食物：分数 +1，蛇身长 +1（尾部不删除），重新生成食物。
- 撞边界（蛇头新格 `x<0 || x>=20 || y<0 || y>=20`）立即结束本局，不穿墙、不环绕。
- 自碰撞（蛇头进入自身蛇身格，排除即将移走的尾格）同样结束本局；这是对边界失败的自然补充，不影响边界验收（意图未禁止自碰撞失败）。
- 状态机：`ready → running → gameover →（重开）ready → running`；可选暂停属扩展点（见架构文档），v1 不强制实现暂停。

## 4. 输入映射

- 方向键 `ArrowUp/ArrowDown/ArrowLeft/ArrowRight` 与 `W/A/S/D`（大小写不敏感）均可改变方向。
- 禁止 180° 反向（例如向右时按左无效），避免蛇头直接撞入自身。
- 同一 tick 内多次输入以最后一次有效方向为准；每次步进最多应用一个方向变化。
- 游戏结束状态下，按 `Space`/`Enter` 或点击「重新开始」按钮重开；进行中忽略重开按键，避免误触。

## 5. 计分与重开

- 分数显示在页面 HUD 的固定元素（`#score`），每次进食后即时更新为当前分数（从 0 开始）。
- 结束状态：画布/遮罩显示「游戏结束 + 最终分数 + 重新开始按钮」。
- 重开复位清单：蛇身坐标与长度复位为初始 3 格、方向复位为向右、分数归零、食物重新随机生成、状态机回到 `ready` 并在首次步进进入 `running`、输入缓冲清空、定时器不重复叠加（先清旧 timer 再启新）。
- 重开入口：页面可见按钮 + 空格/Enter 键，两条路径调用同一 `restart()`。

## 6. 边界与失败判定

- 每步先计算蛇头新坐标，**先判定越界**：任一坐标越界即判定失败并立即停止定时器，不绘制到界外、不做坐标环绕。
- 越界判定发生在蛇身位移之前，保证「撞边界立即失败」且不出现穿墙。
- 失败后不再推进步进，直到重开。

## 7. 验收对照（意图四项硬验收 + 基本可运行性）

| 意图验收 | 本提案保证 |
| --- | --- |
| 键盘控制 | 方向键与 WASD 均可变向，蛇按固定步长持续移动 |
| 计分 | 进食分数 +1，`#score` 可见并即时更新 |
| 重开 | 结束后按钮/按键重开，蛇、分数、食物、方向、状态全部复位 |
| 边界碰撞 | 越界立即失败并停止，不穿墙不环绕 |
| 基本可运行性 | 零依赖零构建，双击 `index.html` 即可运行，启动无外部请求 |

## 8. 非目标

- 联机/多人、排行榜与最高分持久化、账号、关卡与难度递进、道具、移动端触控——均不做（与意图一致）。
- 美术、音效、动画不作硬性要求，保持简洁可读即可。
