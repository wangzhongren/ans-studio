# snake-game 产品意图（v1）

## 1. 产品目标

在项目根目录新建一个可本地运行的贪吃蛇小游戏。玩家用键盘控制蛇移动，吃到食物得分并看到分数，游戏结束后可重新开始；蛇头撞到边界即判定失败并结束本局（不是穿墙）。

目标用户与场景：本地单机单人玩家，打开即可游玩，无需登录或联网。

## 2. 范围（Scope）

- 属新建的本地单人小游戏（单页/单机实现），在项目根目录新建实现。
- 核心能力：键盘控制、吃食物计分与分数显示、结束后重开、撞边界即失败。
- 具体技术栈、运行方式与代码结构由后续方案阶段决定，本意图不锁定实现方案。

## 3. 验收标准（Acceptance）

1. **键盘控制**：可用方向键或 WASD 控制蛇的移动方向，蛇按输入持续移动。
2. **计分**：吃到食物后分数增加，界面上有可见的当前分数显示。
3. **重开**：游戏结束后可重新开始新一局，分数与蛇的位置/长度等状态正确复位。
4. **边界碰撞**：蛇头撞到游戏区域边界时立即判定失败并结束本局，不出现穿墙或环绕。
5. **基本可运行性**：可在本地正常启动并游玩，无启动即崩溃等阻塞性问题。

## 4. 非目标（Non-Goals）

- 不含联机对战或多人模式。
- 不含排行榜/最高分持久化与账号体系。
- 不含关卡系统、难度递进与道具机制。
- 不含移动端触控操作。

## 5. 客户原话与约束

客户原始需求：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）」，即：方向键/WASD 键盘控制、吃食物得分并显示分数、游戏结束后可重开、撞墙（边界）即失败判定；在项目根目录新建实现。

## 6. 质量档位

以「功能齐全、可正常游玩、运行稳定无崩溃」为主；美术、音效、动画表现不作硬性要求。
