## 待客户确认的关键假设（未指定部分，按最小可用默认）

1. 单用户、纯前端、无后端与账号；数据存浏览器本地存储，刷新不丢。
2. 功能只做四条：新增、切换完成/未完成、删除、空状态（不做标签/优先级/日期/过滤以外的扩展）。
3. 质量档位默认生产档（测试、可访问性、真实启动演示均按生产基线执行）。

## 客户提到演进/规模诉求

本轮未提及后续演进（新增状态、导出格式、统计维度、接入方等）。验收标准要求 README 说明扩展点位置，以便后续演进；具体架构选择由提案环节负责，本记录不预设架构。
