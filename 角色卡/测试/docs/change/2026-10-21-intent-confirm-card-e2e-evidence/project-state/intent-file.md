# 待办清单网页应用（todo-list-web）

## 客户原话
> 我想做一个最简单的待办清单网页应用，请先确认需求。

## 主理（Lead）的代为界定
客户只用「最简单」描述功能规模，未指定质量档位。按主理职责：客户未明确选择原型档，
默认生产档，功能范围保持最小。

## 目标
浏览器打开即可用的单页待办清单，能真实操作、刷新不丢数据。

## 范围
- 做：新增待办、勾选完成 / 取消完成、删除、剩余未完成计数、本地持久化、空态与空输入提示。
- 不做：账号与登录、服务端与数据库、标签分类、截止日期、提醒、搜索、原生 App、跨设备同步。

## 验收
见 frontmatter `acceptance`，逐条可核对；验收前需真实启动并演示。
