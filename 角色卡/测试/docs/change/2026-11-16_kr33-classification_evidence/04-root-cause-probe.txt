日期：2026-11-16；Node v24.22.1；Windows 11

## 1. 直接探针（只读调用产品导出，不写盘）

命令（在 kr33ana 工作树内）：
  node --input-type=module -e "import { readGitHostProtectionRequirement } from './src/provider/trunk/impl/git-command.ts'; ..."

输出：
  cwd C:\Users\51054\Desktop\work\ans-studio\.claude\worktrees\kr33ana
  cwd .git lstat: file
  scope cwd: {"state":"unknown","revision":1,"reasons":["Error: git-association-protection-requirement-unknown"]}
  plain scope: {"state":"unmanaged","revision":1,"reasons":[]}            # 无 .git 的临时根
  git-dir scope: {"state":"unmanaged","revision":1,"reasons":[]}          # .git 为普通目录
  git-file scope: {"state":"unknown","revision":1,"reasons":["Error: git-association-protection-requirement-unknown"]}  # .git 为文件

结论：linked git worktree 的 `.git` 是文件（`gitdir: …`），产品按安全口径判“Git 关联保护要求未知”，
不是产品缺陷；规范 checkout（.git 为目录或无 .git）下为 unmanaged，测试继续执行。
