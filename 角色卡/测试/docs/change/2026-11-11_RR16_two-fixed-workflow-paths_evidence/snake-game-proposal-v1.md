# 提案 · 贪吃蛇（snake-game）v1

依据：产品意图 `docs/product/snake-game-intent-v1.md`（v1，schema=project-intent/v1，intentId/flowId=snake-game，客户已确认，decision-req-7a6cca3b6a286459）。本提案不扩范围；与意图冲突时以意图为准并按版本化流程出新版。

## 1. 目标

交付一个单机、单人、可玩的贪吃蛇游戏：浏览器直接打开即可运行；键盘控制蛇移动，吃食物累计计分，撞墙判定碰撞并结束，可重开一局。

## 2. 范围

- 实现四条功能项：A1 键盘控制、A2 计分、A3 重开、A4 边界碰撞（封闭边界、撞墙即结束）。
- 实现隐含最小本体：蛇身随进食增长、食物生成、游戏结束判定。
- 形态：HTML/JS 单页面（多文件静态资源，无构建工具、无外部依赖、无网络、无存储）；若交付环境不支持浏览器，按意图退化为等价的最小可运行形态，并在交付说明写明启动方式。
- 交付物：`index.html` 入口、`README.md` 启动与操作说明、`src/` 下实现代码、`qa/` 下人工验收清单。

## 3. 非目标

不联网、不多人、不排行榜/账号、不持久化存档（刷新即重开、不写 localStorage）、不做美术音效动画、不做移动端触屏适配。WASD、暂停等为可选扩展，默认不实现。

## 4. 验收口径（与意图 v1 一致）

- A1 键盘控制：方向键（↑↓←→）四向均产生可观察响应；以最后一次有效方向为准；拒绝与当前方向相反的非法输入，不出现反向自撞异常。
- A2 计分：吃食物后分数增加；界面有可观察分数显示；分数随每次进食递增；重开后归零。
- A3 重开：提供 R 键或界面按钮；触发后蛇回初始位置与长度、分数清零、结束态解除，无需刷新页面即可立即新开一局。
- A4 边界碰撞：四周封闭边界、非穿墙；蛇头触及/越过边界即判定碰撞并结束，显示可观察结束提示与最终分数；重复测试稳定复现。
- 共同判定：四条均可人工操作观察验证，不依赖特定测试框架或自动化工具。

## 5. 实现与交付约定

- 单页入口 `index.html` 使用普通 `<script>` 顺序加载（不使用 ES module），确保 `file://` 直接打开可运行，不要求本地服务器。
- 无构建步骤、无第三方依赖；不发起网络请求，不读写持久化存储。
- 启动方式与操作说明由 `README.md` 写明。

## 6. 风险与假设

- 假设交付环境支持浏览器；若应用只读环境事实表明不支持，则按意图退化为单文件脚本形态，模块路径与入口需同步调整。
- 假设计分为每次进食固定加分（+1），不含连击/倍率；撞墙即结束、不扣分不反弹；场地封闭不穿墙（均为意图 v1 假设）。
- 假设「重开」可在游戏运行中或结束后触发，行为一致：状态归零并可立即新开一局。
- 风险：单文件内联全部逻辑会导致入口模块与逻辑模块路径冲突；本提案采用多文件静态资源方案规避。
- 待确认项按意图 6.3 处理；若客户答复与假设冲突，须由产品出新版意图后本提案再出新版，不自行变更。
