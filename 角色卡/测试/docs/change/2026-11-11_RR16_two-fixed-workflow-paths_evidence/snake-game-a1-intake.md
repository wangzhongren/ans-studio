## 2. 客户原始目标（原话要点，照录不改写）

做一个贪吃蛇游戏，需具备四条功能项：

1. 键盘控制；
2. 计分；
3. 重开；
4. 边界碰撞（撞墙判定）。

## 3. 四条功能项记录（受理口径，仅记录不扩写）

| 序号 | 客户原话 | 受理理解（待客户/策划确认） |
| --- | --- | --- |
| 1 | 键盘控制 | 玩家用键盘方向输入操控蛇的移动方向 |
| 2 | 计分 | 随游戏进程累计分数并在界面呈现 |
| 3 | 重开 | 游戏结束或任意时刻可重新开始一局 |
| 4 | 边界碰撞（撞墙判定） | 蛇头越过游戏区域边界（撞墙）时判定为碰撞 |

### 4.2 验收口径草稿（待 A2 落成可验收表述）

- 键盘控制：四条方向输入可用，且不会出现反向自撞等明显异常。
