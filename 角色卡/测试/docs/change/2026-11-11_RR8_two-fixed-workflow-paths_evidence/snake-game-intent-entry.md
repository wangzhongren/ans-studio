# 意图：贪吃蛇游戏

## 目标
交付一个可玩、可验收的贪吃蛇游戏：键盘控制蛇在固定矩形边界内移动，吃到食物得分，撞到边界即游戏结束，并可随时重开一局。

## 范围
1. 键盘控制：方向键与 WASD；禁止 180° 反向转向；同一帧内多次方向输入取最后一次有效方向。
2. 计分：每吃到一个食物 +10；显示当前分数与会话内最高分。
3. 重开：任意时刻按 R 重开；蛇、食物与当前分数重置，会话最高分保留。
4. 边界碰撞：蛇头触碰四周边界即游戏结束，不穿墙；自撞同样结束；结束后显示结束提示与本次得分。
5. 运行形态：单页浏览器（单 HTML 文件），离线运行，无后端、无构建步骤。

## 验收标准
见 frontmatter 的 acceptance（A1–A6）。

## 非目标
多人对战/联网/后端、最高分持久化、穿墙与关卡难度、暂停键/触控/音效、多文件工程化与自动化测试框架。

## 约束
仅键盘输入；单页浏览器离线可运行；每个食物固定 +10；最高分仅本会话；撞边界或自撞即结束。
