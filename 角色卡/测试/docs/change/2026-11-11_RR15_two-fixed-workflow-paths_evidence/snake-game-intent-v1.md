# 产品意图：snake-game（v1）

## 目标用户与场景

- 目标用户：想在浏览器里快速玩一局经典贪吃蛇的普通用户（无需安装、无需注册）。
- 使用场景：本地直接双击/打开单个 HTML 文件即可开始游戏，单局数分钟内完成；失败后可立即重开再来一局。
- 理解成本：规则沿用经典贪吃蛇直觉（吃食物变长、撞墙/撞自己结束），不引入需要阅读说明的新机制。

## 要解决的问题

- 客户希望有一个从零新建、自包含、可直接运行的贪吃蛇小游戏，覆盖四项核心能力：键盘控制、计分、重开、边界碰撞。
- 现状：项目为空目录起步，无任何既有代码与依赖（应用只读事实），因此本意图只描述"要什么"，不描述实现方案。

## 范围（本版要做）

1. 键盘控制
   - 方向键（上/下/左/右）改变蛇的前进方向；同时支持 WASD 作为等价方向键（结论：支持，二者等效）。
   - 禁止 180° 反向：与当前前进方向同轴的直接反向输入无效（例如向右行进时按左不会生效）。
   - 每步移动一格，蛇身随头部前进逐节跟随。
2. 计分
   - 吃到食物得 1 分（每个食物固定 +1 分），蛇身长度 +1。
   - 分数在界面可见：展示在游戏画布上方的顶部状态栏（当前分数），吃到食物时即时更新。
   - 食物随机生成在空白格上（不与蛇身重叠）；被吃后立即生成下一个。
3. 重开
   - 本局结束（撞墙或自撞）后，可按 Enter 键或点击"重开"按钮开始新的一局。
   - 重开语义：分数清零、蛇身恢复初始长度与初始位置、食物重新生成；游戏进行中不提供重开入口。
4. 边界碰撞
   - 撞到画布边界（撞墙）立即结束本局：蛇停止移动，画面显示 "Game Over"、最终分数与重开提示。
   - 撞到自身（自撞）同样立即结束本局，表现与撞墙一致。
5. 运行形态与难度设定
   - 单页 HTML + 原生 JS（Canvas 渲染），浏览器直接打开即可玩，不依赖构建工具与后端。
   - 画布/网格：20x20 网格，每格 20px，画布 400x400（上方另设状态栏区域）。
   - 速度/难度：固定速度，每步约 150ms；难度固定，不随分数加速。

## 非目标（本版明确不做）

- 不做音效/背景音乐。
- 不做多人或联机模式。
- 不做移动端触控（仅键盘 + 结束后的重开按钮）。
- 不做最高分记录与跨会话持久化（localStorage 等）。
- 不做穿墙（wrap-around）模式——本版边界碰撞一律为"结束本局"。
- 不做关卡、道具、特殊食物、随分数加速等难度扩展。
- 不做暂停、设置菜单、账号体系与后端服务。
- 不做视觉主题/皮肤切换等美化扩展（界面保持简洁可用即可）。

## 成功/验收标准

- 浏览器直接打开该 HTML 文件即可开始游戏，无需安装、无需启动服务，控制台无脚本报错。
- 键盘：方向键可四向改向；WASD 可用且与方向键等效；同轴直接反向输入无效（蛇不会瞬间掉头自撞）。
- 计分：每吃到一个食物分数 +1、蛇身增长 1 节；顶部状态栏分数即时变化。
- 重开：撞墙/自撞后显示 Game Over 与最终分数；按 Enter 或点击重开按钮后回到初始状态（分数 0、初始蛇身、新食物），可正常继续游戏。
- 边界碰撞：蛇头触墙的下一步立即结束本局，不越界绘制、不穿墙；自撞同样结束。
- 时长与稳定性：正常连续游戏过程中无卡死、无持续增长的资源占用异常。

## 客户原话与约束

- 客户原话（仅记录，不作扩张）："做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。"
- 约束：
  - 新建/新功能包性质（产线路径 A），从空项目起步。
  - 交付物须可直接运行、便于客户本人打开体验。
  - 本版对客户原话未覆盖的细节（WASD、20x20 网格、150ms 固定速度、每食物 1 分、单页 HTML + 原生 JS、结束态重开）由 product 按运营 A2 任务给定的默认取舍落笔，属产品取舍，需在意图确认时由客户确认，不视为客户已确认的追加需求。

## 质量档位

- 档位：**可演示的最小完整游戏**（高于纯原型，低于可发布的商业产品）。
- 含义：四项功能完整可用、界面信息清晰（分数与 Game Over 可见）、单人可直接体验；不要求美术打磨、音效、性能调优或跨设备兼容。
- 不写实现方案：具体代码结构、文件分层与模块划分由后续提案/架构阶段决定。
