1. `[覆盖1] validateTitle`：空/`\t`/`\n`/全角空格/非字符串 → false；1–200 字符（含边界 200/201）→ 正确。

7. `[覆盖3] updateTask 错误`：空白/非字符串标题 → `TITLE_REQUIRED`；>200 → `TITLE_TOO_LONG`；非法 status → `INVALID_STATUS`；null 任务 → `INVALID_TASK`。
8. `[覆盖5] filterTasks`：status/tag/q（大小写不敏感、命中标题或标签）、`all`/空不筛选、多条件 AND、返回新数组、不改入参。
9. `[覆盖5] sortTasks`：createdAt/priority × asc/desc；默认 createdAt+desc；非法值回落；返回新数组。
10. `[覆盖5] sortTasks 稳定性`：同优先级按 createdAt 再按 id，asc/desc 均确定。
11. `[覆盖6] computeStats`：total、三状态键恒在（空列表为 0）、byTag 计数、非数组入参安全。
