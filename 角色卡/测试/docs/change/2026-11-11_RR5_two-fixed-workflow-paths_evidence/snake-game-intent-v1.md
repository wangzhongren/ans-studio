# 贪吃蛇游戏 — 产品意图 v1

## 1. 客户原话（逐字）

> 做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。

**转述**：交付一个可用键盘操作、带计分与重开、并在撞到场地边界时作出碰撞判定的经典贪吃蛇小游戏。

## 2. 目标

交付一个**可在桌面浏览器中直接打开游玩**的经典贪吃蛇小游戏：玩家用键盘控制蛇在网格场地内移动、吃食物得分，撞墙即结束并可重开。目标是「小而完整、能实际玩一局」，而非可扩展的游戏框架。

## 3. 范围（本版要做）

| # | 能力 | 本版口径 |
| --- | --- | --- |
| S-1 | 键盘控制 | 方向键（并兼用 WASD）改变蛇的移动方向；禁止直接反向；按网格步进移动 |
| S-2 | 计分 | 吃到食物加分（默认每食物 +10），分数在界面上实时显示 |
| S-3 | 重开 | 游戏结束后按 R 键或点击按钮重开新局，分数归零 |
| S-4 | 边界碰撞 | 蛇头撞到上/下/左/右任一边界即游戏结束，给出可见结束提示 |
| S-5 | 基础玩法支撑 | 网格场地、食物随机生成于空格、蛇身进食后增长、蛇头撞自身身体亦判结束 |

## 4. 验收标准

- **AC-1 启动**：在浏览器中打开交付的网页入口，游戏立即可见并可开始，无报错、无外部服务依赖。
- **AC-2 键盘控制**：按键后蛇的朝向改变并继续按网格步进；按相反方向键不会导致立即自撞（被忽略或视为无效输入）。
- **AC-3 计分**：吃到食物后分数按既定规则增加，界面分数同步刷新；同一食物不重复计分。
- **AC-4 边界碰撞**：蛇头越过任一方向边界时游戏结束，界面出现可见结束提示，蛇停止移动。
- **AC-5 重开**：结束后可通过界面提示的按键/按钮开始新一局，分数归零，蛇与食物回到初始状态。
- **AC-6 完整流程**：可连续完成「开始 → 移动 → 吃食物加分 → 撞墙结束 → 重开」，过程中无卡死或异常。
- **AC-7 证据形态**：以人工实际运行演示 + 截图/录屏为验收证据，交付说明写明运行方式（打开哪个文件）。

## 5. 非目标（本版不做，待确认）

- 暂停/继续、难度分级或速度递增。
- 音效与背景音乐。
- 移动端触屏与响应式适配。
- 最高分记录与本地持久化、排行榜。
- 多语言、关卡、皮肤/美术素材。
- 穿墙模式（从对侧出现）与撞墙反弹行为——本版统一按「撞墙即结束」。
- 账号、联机、后端服务、数据收集。

## 7. 假设与未解决缺口汇总

**假设（全部待客户确认）**：
- A-1 桌面浏览器网页形态。
- A-2 纯 HTML/CSS/JS、无外部依赖。
- A-3 固定约 20×20 网格、简单色块、无美术素材。
- A-4 撞墙即游戏结束（非穿墙/非反弹）。
- A-5 每食物 +10 分、速度固定不递增。
- A-6 R 键或按钮重开、分数清零。
- A-7 蛇头撞自身身体亦判结束。
- A-8 初始长度 3 格、食物仅生成于空格、固定移动节奏。

**未解决缺口**（需客户/幕僚澄清，若答复与上述假设不同，应出新版本意图）：
1. 平台与技术栈是否确有指定。
2. 撞墙后是「结束」「穿墙」还是「反弹」。
3. 是否需要暂停、难度/加速、最高分持久化、音效、移动端支持。
4. 正式验收的演示人与演示方式（录屏/现场/截图）。
