---
intentId: snake-classic-game
flowId: snake-game
goal: |
  交付一个可直接在浏览器中打开游玩的经典贪吃蛇小游戏，具备键盘控制、实时计分、撞墙结束后的重开，以及明确的边界碰撞处理。
scope: |
  - 键盘控制：方向键（并兼用 WASD）改变蛇的移动方向，禁止 180° 反向自撞，按网格步进移动。
  - 计分：吃到食物加分（默认每食物 +10），分数在界面上实时显示；同一食物不重复计分。
  - 重开：一局结束后按 R 键或点击界面按钮重开新局，分数归零。
  - 边界碰撞：蛇头撞到场地任一边界判定游戏结束，出现可见结束提示，蛇停止移动。
  - 基础玩法支撑：约 20×20 网格场地、食物随机生成于空格、蛇身随进食增长、蛇头撞自身身体亦判结束。
  - 运行方式：纯前端单网页入口（HTML + CSS + JavaScript，无构建工具、无外部依赖），桌面浏览器直接打开即可游玩、无需联网。
acceptance: |
  - AC-1 启动：浏览器打开网页入口即可见并可开始，无报错、无外部服务依赖。
  - AC-2 键盘控制：按键后蛇朝向改变并按网格步进；按相反方向键不会导致立即自撞（忽略/无效输入）。
  - AC-3 计分：吃到食物后分数按规则增加且界面同步刷新；同一食物不重复计分。
  - AC-4 边界碰撞：蛇头越过任一方向边界时游戏结束，界面出现可见结束提示且蛇停止移动。
  - AC-5 重开：结束后可通过提示的按键/按钮开始新一局，分数归零，蛇与食物回到初始状态。
  - AC-6 完整一局：可连续完成「开始 → 移动 → 吃食物加分 → 撞墙结束 → 重开」，无卡死或异常。
  - AC-7 证据形态：以人工实际运行演示 + 截图/录屏为验收证据，交付说明写明运行方式（打开哪个文件）。
nonGoals: |
  - 暂停/继续功能。
  - 难度分级或随分数递增的移动速度。
  - 音效与背景音乐。
  - 移动端触屏操作与响应式适配。
  - 最高分记录与本地持久化（localStorage 等）。
  - 多语言、排行榜、关卡、皮肤/美术素材。
  - 穿墙模式（从对侧出现）与撞墙反弹行为——本版按「撞墙即结束」处理。
  - 账号、联机、后端服务与数据收集。
constraints: |
  - 技术栈假设：纯 HTML + CSS + JavaScript（Canvas 或 DOM 网格），不使用构建工具或外部依赖。
  - 运行平台假设：桌面浏览器（Chrome / Edge 等现代浏览器），不承诺移动端。
  - 界面假设：固定约 20×20 网格，简单色块表现，不使用美术素材。
  - 碰撞假设：撞墙即游戏结束（非穿墙、非反弹）；蛇头撞自身身体同样判结束。
  - 计分与节奏假设：每食物 +10 分；移动速度固定不递增；食物仅生成在空网格。
  - 重开假设：结束后按 R 键或点击按钮重开，分数清零。
  - 以上均为「假设/待确认」，未经客户确认不得视为已确认需求。
