## 客户原话目标

> 做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。

## A1 受理结论（仅供 A2 撰写使用，非产品意图正文）

**一句话目标**：做一个可在浏览器/本机运行的单人贪吃蛇游戏，玩家用键盘控制蛇移动，吃食得分，撞墙或自撞结束，可随时重开。

**初步范围**
1. 单局单人游戏循环（开始 → 进行 → 结束 → 重开）。
2. 键盘方向控制（方向键/WASD 至少一种，禁止反向自撞）。
3. 计分：吃到食物加分，当前分数与最高分展示。
4. 重开：一局结束后可立即重开，分数重置。
5. 边界碰撞：撞墙即结束（规则由 A2 明确是否含自撞）。
6. 基础界面与可运行入口（技术栈/运行方式待 A2 确认）。

**验收要点（初步）**
- [ ] 键盘控制可连续转向，且不能瞬间 180° 反向。
- [ ] 吃食物后分数正确增加并实时显示。
- [ ] 重开后棋盘、蛇身、分数回到初始状态。
- [ ] 撞到边界立即结束并给出可见的结束提示。
- [ ] 游戏可被稳定启动/打开并按上述规则完整玩一局。

**已知约束 / 待澄清（交 A2）**
- 技术栈与运行环境（纯 HTML/JS 单文件、桌面或其它）未定。
- 自撞是否结束、是否有速度递进/难度、食物生成规则未定。
- 最高分是否需要持久化（localStorage 等）未定。
- 是否需要移动端触控，客户原话只要求键盘控制。
