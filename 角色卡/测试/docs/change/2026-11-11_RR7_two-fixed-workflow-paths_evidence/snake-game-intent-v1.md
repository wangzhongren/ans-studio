# snake-game 产品意图 v1

## 目标用户与场景

- 目标用户：想在浏览器里随手玩一局贪吃蛇的普通玩家（单人、本地、无需注册）。
- 使用场景：打开页面即可开始；用键盘方向键操控蛇去吃食物刷分；撞墙后看到结束状态，按键/点击立即重开再来一局。

## 要解决的问题

客户希望有一个规则简单、即开即玩、具备经典贪吃蛇核心循环（移动—吃食—计分—失败—重开）的小游戏；现状没有该产物，需要一个可运行、可验证其四项核心能力的完整单机版本。

## 范围与非目标

范围见 frontmatter 的 `scope`，非目标见 `nonGoals`。本版以「键盘控制、吃食计分、重开、边界碰撞」四项客户明确要求为核心，其余能力不主动扩张。

## 成功 / 验收标准

以 frontmatter 的 `acceptance` 为准：键盘控制可连续转向且不能瞬间反向、吃食计分正确并实时显示、重开回到初始状态、撞到边界立即结束并提示、整体可启动并完整玩通一局，且达到原型可用质量档。

## 客户原话与约束

- 客户原话：「做一个贪吃蛇游戏（键盘控制、计分、重开、边界碰撞）。」
- 约束要点：以客户四项要求为必须能力；不加入客户未提出的联机、排行、触控等；质量以原型可用为界。

## 质量档位

原型可用档（playable prototype）：规则正确、可玩通、反馈清晰；不做美术与性能层面的打磨要求。

## 待客户在 A3 确认的取舍（本版已给出默认假设）

1. 技术栈与运行方式：默认浏览器单页应用、本地打开运行；若需桌面程序或其它形态，另出新版本。
2. 自撞规则：默认自撞即结束（与经典一致）；客户若要求撞墙结束但自撞穿行/免疫，需变更。
3. 难度递进：默认恒定速度、不做加速；客户若要难度曲线，作为后续变更。
4. 最高分持久化：默认本会话内展示；是否跨刷新持久化（本地存储）待确认。
5. 移动端触控：列为非目标；客户若需要触控，作为后续变更。
