# 测试边界

## Section 1: 可修改文件与目录

| 类型 | 可操作路径 | 用途 |
| --- | --- | --- |
| 目录（测试） | `test/测试/` | 跨角色联调、完整流程与回归用例，及其夹具与测试辅助代码 |
| 单文件 | `角色卡/测试/feature-map.md` | 功能导航 |
| 单文件 | `角色卡/测试/memo.md` | 本角色工作备忘录 |
| 单文件 | `角色卡/测试/changelog.md` | 本角色治理变更记录 |
| 单文件 | `角色卡/测试/functional-description.md` | 模块笔记与代码位置 |
| 目录 | `角色卡/测试/docs/design/` | 测试方案 |
| 目录 | `角色卡/测试/docs/feature/` | 测试相关的稳定说明与流程图 |
| 目录 | `角色卡/测试/docs/change/` | 变更记录 |
| 目录 | `角色卡/测试/docs/fix/` | 修复记录与问题记录 |

测试辅助代码不得被产品代码引用。本边界不授权修改业务源码、`src/common/shared/`、其他角色的私有框架或单元测试、构建配置、角色卡或权限配置。

未列路径默认只读。新增测试目录、改动归属或增删逐条列出的路径，须先由 ANS Governance 更新 Section 1 并经客户确认。
