  2. **每个内置角色独立成一个模块**（六个角色模块，边界/依赖/接口/迁移）；
  3. **每个内置角色对应一个维护角色**（共六个维护角色候选）；团队是否新增/拆分/合并由统筹按五维判断，闸门 2 客户确认，人事写卡。
