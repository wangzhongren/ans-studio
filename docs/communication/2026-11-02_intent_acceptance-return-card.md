# 意图确认：验收报告返回幕僚的卡片特殊显示 + 原文直出

- 日期：2026-11-02
- 提出人：客户
- 记录角色：ANS 沟通（Communication）
- 闸门 0 状态：**已确认（2026-11-02）**
- 变更类型：客户可见报告卡展示修订；预计风险档位 **T2**（由策划定档）

## 客户原话

> 验收给他卡片要特殊显示，而且要原本直接渲染显示。
>
> 验收返回的卡片的
>
> 返回到幕僚

（上下文：验收报告由 verifier 交回幕僚/chief 时，聊天流里是一张普通报告卡；客户希望它对「验收」有特殊身份显示，并且直接展示验收报告原文。）

## 意图理解

验收结果返回幕僚时，展示给幕僚的报告卡应：

1. **特殊显示**：与普通角色报告卡区分开，明确标识这是「独立验收」结果（徽标/标题/配色等，具体样式由方案定）。
2. **原文直接渲染**：验收报告原文（至少 `report.summary.text`，是否含全部证据待确认）直接在卡面渲染，不再只显示 180 字/4 行预览 + 「查看全文」折叠。

## 现状（只读核查，2026-11-02）

- 验收回交在聊天流中走 `HandbackRow` → `ReportCard`（`app/renderer/src/chat/ChatRow.tsx:643-654`）。
- `ReportCard` 对所有报告统一使用 `reportPreview(full)`——**最多 180 字 / 4 行**（`app/renderer/src/chat/report-view.ts:131`），全文放在「查看全文」的 `<details>` 折叠里（`app/renderer/src/shell/ReportCard.tsx:140-210`）。
- 报告来源可用于识别 verifier：`report.source.roleId`；验收任务的 report 可能还带 taskId/stepId。当前没有「验收报告卡」的专用样式/标记。
- 不改变验收判定、路由、持久化或报告声明语义；只改验收回交卡的展示。

## 范围与待确认

- **Q1 目标卡片**：
  - A（默认理解）：verifier 验收报告**返回到幕僚**的那张报告卡（HandbackRow/ReportCard）；
  - B：客户侧的验收决定卡（DecisionDialog 的 acceptance 卡）；
  - C：两者都要。
- **Q2 特殊显示**：
  - A（推荐）：独立验收徽标/标题 + 与普通报告卡不同的配色/边框；
  - B：只加「独立验收」标题/徽标；
  - C：先只做原文直出，样式后续再定。
- **Q3 原文范围**：仅 `report.summary.text` 全文直出；还是同时把全部 `evidence` 也直出？是否保留「查看全文」折叠（原文已直出时可去掉）？
- **Q4 适用视图**：只幕僚视图，还是所有查看该报告的角色/客户视图都特殊显示？
- **Q5 安全/边界**：原文超长时是否仍保留有界上限（如整段 16 KiB 投影）？缺报告/播放旧记录时如何降级？
