## 复核结论

**建议修订后提交。** F1–F5 影响新增非只读定义的可执行性、A 的真实卡和延迟验收回交，或新旧实例写入安全。先定稿三份参考图与最小能力契约、原入口接线及占用边界。分支内可先调查旧入口和准备兼容注册、定义解析与 Windows 包候选，待上述契约明确后连接高风险写入与发布作用端。
